# 第一部分：中国

### 1. 浙大全球首次真机跑通量子高速内存【量子·浙江大学·实验室阶段】📈
浙江大学物理学院、计算机学院、软件学院与宁波国际科创中心联合团队，在超导量子芯片「天目2号」上全球首次真机实现量子随机存储器（QRAM），相当于给量子计算机装上「高速内存」，成果发表于《自然·物理》。原型实测调取4位数据准确率80.9%、8位60.4%，优化后线路深度比未优化方案降低30%以上；团队还让路由量子比特兼任监视器以自动剔除无效查询。这意味着自2008年提出的QRAM理论架构首次在真实芯片上跑通，量子算法按地址取数的最大瓶颈有了工程突破口。来源：[腾讯新闻转载人民日报报道](https://news.qq.com/rain/a/20261121A0EQ3K00)

**机会点**：QRAM工程化刚破零，量子软件工具链存在空位——量子算法团队第一步可基于公开论文复现该线路并做成开源取数模块，供后续算法研究引用验证。

### 2. MiniMax公布大模型自动密码分析成果【AI·MiniMax·研究成果】📈
11月22日晚，MiniMax公布基于最新内部模型的系统性自动化密码分析研究：针对历届NIST国际密码标准化竞赛，首次攻破多个此前尚无已知实际攻击的候选算法，并将多项停留在理论阶段的攻击推进到秒级至分钟级即可完成，刷新了新型分组密码的最高破解轮数纪录；在求解公钥密码基石类数学困难问题时，较当前最优算法实现数百至数万倍实测加速。这是国产大模型在AI4S方向上交出的可验证成绩单，与Anthropic的黎曼猜想证明同日呼应。来源：[上观新闻/网易](https://www.163.com/dy/article/LCD5RF8L055040N3.html)

**机会点**：大模型具备破解能力意味着防御侧评估需求同步出现——安全公司第一步可基于公开的NIST候选算法库搭建「AI辅助密码红队评估」标准流程，向金融与通信客户出售评估服务。

11月21日，国产120kV冷冻透射电子显微镜TH-F120C在广州发布：加速电压120kV、信息分辨率0.23纳米，场发射电子枪、低漂移高压电源、磁透镜恒流源、直接电子相机、冷冻样品系统与整机控制软件全部自主研制，高压稳定度从上一代的10ppm/h提升到2ppm/h。项目由生物岛实验室牵头，联合广州实验室、中科院广州生物医药与健康研究院等攻关五年；团队计划2027年推出高通量智能机型、2029年实现300kV国产化，打破赛默飞、日本电子的整机垄断。来源：[新华财经早报](https://www.cnfin.com/hg-lb/detail/20261122/4498612_1.html)

**机会点**：整机国产化后下游服务空位打开——高校与医院周边的服务商第一步可与设备团队谈定配套培训、冷冻制样耗材供应与数据软件支持，做「设备+耗材+解析服务」打包。

**机会点**：诊断卡机制本身可产品化——评测服务商第一步可接入该开放榜单，为机器人公司输出「失败原因诊断报告」，帮其决定补数据还是补执行器。

## 本篇机会点小结

**一、最值得动手的一条**：本篇国际第12条——「Agent凭证与提示词防护」。Together AI 的泄露事件证明 AI 编码 Agent 会不经意间把凭证提交进公开仓库，且已有成规模的提示词样本外流；做给所有用 Agent 写代码的工程团队，第一步做一个提交前密钥/凭证扫描的 Git hook 或 CI 插件，万元级成本、两周内即可通过开源下载量和企业试用获得第一个正反馈。

**二、被验证的需求**：国内第8条长江存储份额38.5%登顶并再建三厂，清洗抛光刻蚀设备订单已在流向北方华创、中微；国内第5条腾讯 Hy4-flash 首日 Token 调用量超50万亿，低成本推理有真实用量；国内第9条脑机接口全球1175家企业，变现已跑通科研与医疗两条路；国际第4条 alphaXiv 35个实验室让936个 Agent 干了12周活，科研机构已在为 Agent 科研投入算力成本。

**三、明显的空位**：国内第6条与国际第2条显示具身智能评测只有成功率没有失败归因，Mind2Act World 刚把诊断卡做出来，第三方独立复现与诊断报告服务基本空白；国内第4条万元级MEMS质谱还在中试，便携气体检测的应用场景没人先行验证；国际第8条自驱实验室只在一个染料任务上闭环，通用仪器的低成本复现没人做；国际第10条欧盟把「实测跑分」写进招标，而国内算力采购验收仍普遍只看卡数，第三方验收方法论是空位。

**四、本篇结论**：本篇说明 AI 正在从「能聊天」变成「能证明定理、能破解密码、能操控机器人、能自己做实验」的可验证生产力，同时 Agent 自己成为新的安全与质量风险源；而机器人、脑机接口等硬件赛道已进入比拼真实落地能力的阶段，概念演示正在失宠。
