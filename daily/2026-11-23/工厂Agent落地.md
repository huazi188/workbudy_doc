## 第一部分：国内

### 1. 赛轮东营工厂用工业大模型重排轮胎排产，单厂年省废料近千万元 【排产调整·其他·未披露】

轮胎厂的排产是「两只钟表赛跑」：订单交付倒计时与胶料半成品允许存放时效同时约束，密炼供料、半制品加工、成型、硫化环环相扣，原来靠调度员人工权衡哪个规格先做、哪台设备接单、模具是否空闲，排错一格半制品过期就全损。青岛思锐卓远（依托国家橡胶与轮胎工程技术研究中心孵化）研发的「思锐华宸」工业大模型，把订单、设备、模具、物料、半成品时效和物流约束全部纳入排产条件，生成细化到每个班次、每台机台的生产计划，急单响应与频繁切换的代价也要在模型里一起权衡。护栏做法是把橡胶材料加工知识、设备能力、不可突破的工艺条件、必须遵守的排产规则和质量放行规则直接写进模型约束，而不是让模型自由发挥；同一平台还在多地工厂落地X光钢丝自动判级、气泡检测、胶料错放识别等质检应用。落地数字：东营工厂排产计划准确率、执行率达96%，整体生产效率提升20%，单厂每年减少半制品过期与废料损失近1000万元（[人民网山东](https://sd.people.com.cn/n2/2026/1122/c166192-41757475.html)）。复制门槛明确：这套模型的地基是团队二十余年轮胎制造实践沉淀的工艺知识，换行业等于重建知识库，但同行业内复制路径清晰。模型底座、是否 Agent 编排、排产建议谁审批均未披露。缺口：Agent 编排结构与人工审批点未披露。

**机会点**：轮胎行业排产已被验证值近千万元一年——给同行业中小轮胎厂做轻量排产约束建模服务，第一步拿到一家厂的胶料时效和模具匹配数据做单厂试点，1-3 个月可验证执行率变化。

### 2. 歌尔精密电声工厂：仿真验证前置+智能APS排产，换产效率提升80% 【质检异常·电子代工·未披露】

歌尔股份的精密电声器件工厂（智能耳机、手机喇叭等核心组件，公差以微米计、千万件规模）以自研 GPS 制造模式为系统底座，构建「数据+多模态大模型+工业智能体」端到端技术栈。质检异常环节，高清工业相机与自研视觉算法组成全天候在线感知网络，配合焊点质检 CV 垂域大模型「一套模型统御多场景」，解决碎片化小模型反复适配训练的顽疾；复杂工序先在多层次数字孪生体系里仿真验证，再下发产线执行——这是本条最值得抄的护栏设计。排产侧，自研智能 APS 自动排上千张工单并做缺料风险自动预警，与在线感知网络、自研装备协同联动。效果数字：模块化柔性产线换产效率提升80%，综合良率与订单交付周期改善（未给具体值），该工厂入选 2026 年度领航级智能工厂培育名单（[新浪证券](https://finance.sina.com.cn/stock/observe/2026-11-23/doc-inizsuwh2348435.shtml)）。复制门槛：歌尔明确把 GPS+AI 体系向更多业务板块复用，但对外输出尚无路径；智能体编排、模型选型、人工审批点全部未披露。缺口：Agent 编排细节与护栏参数未披露。

**机会点**：「仿真验证前置」这条护栏是现成的生意切口——给换型损失大的电子代工厂做换产前的数字孪生验证服务，第一步选一条高换型损失产线做「改参数先过仿真」的对照试验。

### 3. 威海天力电源自建NPI智能体：百项工作筛后二十项留人判断 【工艺研发·电子代工·未披露】

新品导入（NPI）是制造业最烧脑的环节：工艺参数怎么定、质量风险藏在哪，原来全靠老师傅经验和人工对比，一个新品导入要耗费一个多月。威海天力电源（电源科技企业）的 NPI 智能体把企业 20 多年积累的各领域专家经验，与国家法规、行业规范、标准库要求融合成知识库，在生产之前分析技术资料判断哪里可能出问题并同步给出解决方案，还对初试项目全流程做标准化梳理精简。人工介入点设计得很清楚：智能体自动筛掉大部分事务，关键判断留给人——总经理的表述是「原先一百项工作，经智能体筛选后可能只剩二十项需要人工处理」。该公司还围绕人机料法环陆续开发设备点检数字员工、SMT 料站表管理 AI 助手、AI 定价助手等（[威海火炬高技术产业开发区](http://www.whctp.gov.cn/art/2026/11/23/art_41728_6759465.html)）。效果数字偏定性：100 项筛后 20 项的筛选比例可查，新品导入周期缩短的具体值未披露。复制门槛是本条核心：整个智能体依赖企业自身 20 年专家经验语料，每家工厂必须重建知识库，这既是门槛也是服务空间。缺口：模型、框架、对接系统与写权限边界未披露。

**机会点**：NPI 知识库每家都要重建但没人做成通用工具——第一步帮一家电子厂把新品的 DFM 检查清单结构化成知识库做单个场景试点，知识库工程本身就是可收费的交付物。

### 4. 蜂巢能源基于MES数据链路自研六大AI工具，质量日报40分钟变1分钟 【班次报表·锂电光伏·工作流】

动力电池厂的班组质量日报原来靠手工汇总数据、制作图表、整理结论，一套流程约 40 分钟。蜂巢能源数字化团队锚定生产一线痛点，综合运用 MES 数据链路自主研发六大 AI 工具，5 个月建成「机器承接重复劳动、工程师专注专业判断」的人机协同模式：现在下达一条指令，不到一分钟即可自动完成取数、分析、可视化、结论推送全流程，实现零人工干预。从描述看这是指令触发的自动化工作流而非自主循环 Agent，但取数-分析-推送的链路、与 MES 的数据对接方式完全可照着复刻。效果数字：质量评分日报从约 40 分钟缩到 1 分钟以内，分选查询效率较原有报表提升约 12 倍，每月节约人工 15 小时以上（[上饶经开区](https://www.srkfq.gov.cn/srkfq/006/202611/8d4bcc4172ac48b5bb5b2e679a4cf465.shtml)）。复制门槛：六大工具绑定自身 MES 数据链路，换厂要重做接口；工具清单、模型框架、护栏（日报结论谁审核）均未披露。缺口：六大工具构成、护栏未披露。

**机会点**：这是本篇门槛最低的复刻对象——给有 MES 的中型厂交付「一份 40 分钟级人工日报改一键生成」，两周内就能让甲方看到第一个正反馈。

## 第二部分：国外

### 5. 英伟达发布FOX工厂运营蓝图，西门子接入做根因分析与检测校准 【设备维护·电子代工·未披露】

英伟达在 GTC 柏林大会推出工厂运营蓝图 FOX 的早期访问版本：一套软件框架，帮助开发者创建能监控工厂运营、调查生产问题、协调设备与系统间活动的 AI 智能体——相当于给「工厂环节 Agent」提供了官方参考骨架。西门子正把基于 FOX 开发的智能体整合进 Intelligence Center X 平台，支持工厂管理和根因分析，估计该方法有望带来 20% 的成本节约；其德国埃尔兰根电子工厂还用 Cosmos Data Factory 生成合成缺陷图像用于电路板检测，据称把检测校准时间缩短 40%。工具链为 CUDA-X、Omniverse、Cosmos、Isaac 加上西门子 ICX；奔驰则将 AI 视觉检测用于挡风玻璃装配验证。护栏（智能体能否动设备、谁来审批）与智能体分工细节均未披露（[腾讯新闻](https://news.qq.com/rain/a/20261123A03VQE00)）。复制门槛：FOX 是给开发者的蓝图，接入仍需自建设备数据通道，中小厂直接照抄有距离。缺口：智能体数量、人工介入点、护栏未披露。

**机会点**：FOX 只覆盖大厂生态——对标它给中型厂做一个「报警→根因候选→建议动作」的单产线根因智能体 MVP，蓝图结构公开可抄，第一步从一条产线的报警数据接入做起。

### 6. 西门子用MCP打通增材制造：Agent选夹爪、改几何、仿真验证、备产一条链 【工艺研发·机械加工·单Agent】

西门子展示了首个端到端的增材制造数字线程 agentic 工作流：用户用自然语言描述一个物体和任务，Agent 选定夹爪类型，在 Designcenter 里自适应修改几何，然后仿真验证，并通过 MCP 协议直接调用工程软件函数完成机器人接口校验，最后送入与 EOS、AM Solutions 共建的自适应增材制造单元打印（演示对象是 AGIBOT 机器人夹爪）。这条链把原来「工程师手改设计→单独仿真→备产」的三段式人工流程压成一条 agent 链，设计、仿真、生产被当作一条连通的工作流而非三个独立工序。护栏目前只有「先仿真验证再备产」一道，人工审批点、错误回滚机制未披露，也未给出任何性能基准数据（[Wisevoter](https://wisevoter.com/world/2026/11/22/siemens-agentic-ai-additive-manufacturing-digital-thread)）。复制门槛：需要在自家工厂与伙伴环境内跑通，外部工厂何时可用未披露；但 MCP 让 Agent 调工程软件函数的做法任何工业软件厂商都能照做。缺口：护栏与性能基准未披露。

**机会点**：西门子验证了「MCP 连接 Agent 与工程软件」这条路——国内 CAD/CAE 生态还没有人做，第一步给一款国产仿真软件写 MCP Server 封装，谁先做成谁的软件就能进 Agent 工作流。

### 7. 15个Claude Code子代理开发电机产线控制系统：工单发布等操作硬性禁止Agent执行 【工单流转·机械加工·多Agent】

一个开发者用 15 个 Claude Code 子代理（7 个 Opus 做决策、7 个 Sonnet 做执行）为小规模电机生产搭建控制系统，含 Python 服务器与车间安卓平板。架构上每个子代理用 markdown 文件严格限定工具白名单与推理模型，任务按 1-3 天周期拆分，执行链固定从数据库经后端、测试到客户端。护栏设计是本条最有价值的部分：**发改版、领料、发布工单这类财务敏感操作被规则硬性禁止 Agent 执行、只留给人**；专职的发布控制代理只有 Read、Glob、Grep、Bash 四个工具、物理上无法改代码，只按真实构建与测试结果如实验收；子代理一律不许写 git，提交权垄断在主代理手上。这套边界的来历是一次真实事故：8 月一个未受控代理把 PR 刷到 4000 多行直接合入主干，之后才拆出角色边界（[The Value Engineering](https://thevalue.engineering/news/ai-agent-commit-control-economics-and-risks.html)）。效果无量化数字，但教训明确：模型口头报告的「测试全绿」不可信，必须有只读验收代理做实证。复制门槛低：角色边界就是一组 markdown 提示词模板，任何给工厂搭软件的团队都能直接套用。缺口：上线后生产侧运行数据未披露。

**机会点**：把「无写权限验收代理+敏感操作白名单」这套护栏做成开源模板或提示词包，卖给正在用 Agent 开发工厂软件的团队——成本千元级、两周可发布，是本篇最轻的切入点。

## 本篇机会点小结

**一、最值得动手的一条**：第 4 条（蜂巢式质量日报自动化）。给有 MES 的中型制造厂（锂电、光伏、注塑均可）做「一份 40 分钟级人工日报改一键生成」的单点交付，取数-分析-可视化-推送的链路在本条里已完整披露，照抄即可；第一步选定目标厂的那份日报，两周内即可拿到第一个正反馈，验证周期最短、甲方 IT 团队 5 个月自研的事实也说明这件事难度不高但需求真实。

**二、被验证的需求**：第 1 条已经赚到钱——单厂每年减少半制品过期与废料损失近 1000 万元，排产准确率/执行率 96%；第 2 条换产效率提升 80% 并拿下国家级领航工厂认定；第 5 条西门子给出 20% 成本节约、检测校准时间缩短 40% 的厂商数字；第 4 条每月节约人工 15 小时以上。这些数字说明「工厂环节 Agent/大模型」的预算已经在真金白银地花。

**三、明显的空位**：其一，编排细节集体缺失——第 1、2、3、5 条的 Agent 编排结构、人工审批点全部未披露，说明「能照着搭的方案骨架」在中文世界仍是稀缺品，谁能把护栏和审批点写成模板谁就有位置；其二，第 3 条的 NPI 知识库每家工厂都要重建、无人做成通用工具；其三，第 6 条的护栏只有一道仿真验证，工程软件侧的 Agent 治理（审批、回滚、权限）还是空白，国内 CAD/CAE 的 MCP 封装也无人做。

**四、本篇结论**：本篇说明工厂 Agent 正在从「效果故事」转向「标准接口与护栏工程」——国外厂商在抢 MCP 这类连接标准，国内头部工厂用仿真前置、只读写边界把风险锁死，但可复制的编排骨架与护栏模板仍留在原地，这正是独立服务方今年的窗口。
