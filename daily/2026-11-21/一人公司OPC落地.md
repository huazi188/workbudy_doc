## 第一部分：国内

### 1. 一人用智能体给本地商家做营销代运营，月净利五千到六千 【获客·1人·<1万】

业务是给二三线城市餐饮、美容、汽修等本地小店做线上营销代运营，按 698 / 1398 / 2398 元三档月费收钱，客户是没时间做内容的门店老板。环节拆分：内容生产、数据采集、定时发布、客户答疑全部由基于开源框架 OpenClaw 改造的智能体承担（含知识库、人工审核节点、每日运营日报与每周数据周报自动推送），本人只管签约、收款、回访和兜底，每家店每天平均花不到半小时。每月固定成本控制在 1000 元以内：云服务器约 300 元、大模型接口 200-400 元、图片素材与字体授权 100 元以内、平台企业号认证与第三方工具分摊不到 200 元。单位经济：稳定签 6-8 家店，取 5 家 A 档加 2 家 B 档月营收约 6274 元，净利润 5000-6000 元，活动策划另收单笔 500-1000 元。卡在获客：交付能力有余但签约靠本人跑商圈地推，签单能力就是天花板，且发布绑定真实账号凭证存在封号与安全风险。SOP 已拆成四层可执行子任务、流程本身可复制，但商家信任建立在本人身上，本人离开两周新签约和异常处理会停。本人自述，未经第三方核实。[来源](http://www.wmrh.cn/news/65437)

**机会点**：把这套「本地商家营销智能体」四层架构连同三档套餐定价做成模板，卖给想做同类生意的一人运营者，或按城市招募只负责签单的合伙人——第一步先选一个城市品类（如美容或烧烤）把签约话术与交付SOP打包成一份文档试卖。

缺口：第一批商家如何签下（获客渠道细节）未披露。

### 2. 扫脸打分出海App：一人运营，月流水6.5万、落袋2万 【获客·1人·5-20万】

业务是把一张自拍拆成六个分数加一份改善路线，卖给在意外形的年轻人，订阅制 9.99-59.99 美元，实际均价约 19 美元/月，484 个活跃订阅月流水 9231 美元（约 6.5 万元人民币）。交付环节全自动化：AI 出分出建议，一人每周只投入几小时看数据，没有客服和社群。获客全靠付费投流：一条素材约 16 美元买到一个付费订阅，用户终身价值 30-35 美元，估算月广告支出约 4600 美元（约 286 个新订阅）；素材打法是每轮 10-20 条 AI 生成的同格式变体跑量，跑得动的每三天最多加预算 20%，跑不动当天杀。单位经济：应用商店抽 15% 后减广告费，月落袋约 3200 美元（约 2 万元人民币）——流水 6.5 万和现金 2 万差三倍。卡点极硬：用户平均只留 1.6 个月、产品没有第二次需求、广告一停流水当月归零；商店评分仅 3.0 推高获客成本，外貌打分还属应用商店审核灰区，靠同一产品挂两套名字两套价格在不同市场钻审核缝隙。打法本身是一张可复制的投流公式（先给结论再亮价格+素材量产），但前提是先有一笔能亏的广告预算。订阅数与流水来自第三方订阅追踪，收入口径来自创始人公开访谈。[来源](https://cloud.tencent.com/developer/article/2789109)

**机会点**：这类「一次性判断」订阅App的生死线在素材量产速度与获客成本监控，可以先做给同类出海一人开发者的小工具——AI素材批量变体加单日获客成本预警，第一步用自己或朋友的App小额投流测一轮。

缺口：订阅档位结构、API与服务器成本未披露。

### 3. Coze工作流接抖店夜间客服：月费2680元一店，毛利65% 【售后·1人·未披露】

业务是给女装类目抖店搭AI客服工作流，按 2680 元/月/店收费，复杂投诉与纠纷仍转人工。交付环节由 Coze 工作流自动回复咨询，本人每周维护 3-5 小时（改知识库、看失败会话、处理插件报错）。成本：Coze 专业版年付折算月几百到一千多元，加模型按会话计费；对照组是人工客服——一店夜间需两人、综合成本约 15600 元/月，且夜间首响 48 秒无人应答客户就流失。毛利能留在 65% 左右，算上每周 5 小时维护，净利取决于一人能同时管几家店。卡点：维护时间是隐形天花板，知识库更新和插件报错都压在本人身上；平台规则变动可能让工作流一夜失效。获客方式与在管店铺数未披露。[来源](https://deep-learning.blog.csdn.net/article/details/171019834)

**机会点**：夜间客服是抖店最痛、人工最贵的时段，可按「2680元/月/店」的定价在二线城市复制——第一步免费给一家抖店跑一周夜间咨询，用首响时长和挽回订单数据换签约。

缺口：客户数、获客渠道与月流水总额未披露。

### 4. 黄金行情小程序：10天做完，月广告收入几百块 【获客·1人·<1万】

业务是免费查金价的工具小程序，收入靠广告，本人自述每天几块到十几块，一个月约几百元、够交话费。交付环节几乎零维护：数据源用免费接口加重试机制加备用源，实现商业级可用性；开发含审核预留共10天。成本极低：数据 API 十几到几十块/月（天行数据、聚合数据等量级）。卡在获客与复购：无涨粉机制、工具用完即走、无社区内容、缺裂变手段，本人复盘列出的补救方向是金价到价微信提醒、AI每日100字行情点评、金价对比分享图——说明连这么便宜的交付也救不了没有获客设计的工具。该条为本人自述复盘。[来源](https://mffb.com.cn/a/559142.html)

**机会点**：机会不在复刻这款小程序（月入几百元不值当），而在把「到价提醒+分享裂变」这套获客组件做成小程序模板层的标准件卖给同类工具开发者——第一步先给一款已有日活的查询类小程序加提醒功能，看复访率能否翻倍。

缺口：确切月收入与用户量未披露。

## 第二部分：国外

### 5. 一人营销代理：300美元/月AI订阅撑起六位数收入 【内容·1人·未披露】

业务是一人SEO/营销代理，客户是本地垂直企业（如牙科IT服务商），另卖 Claude Code 技能包等数字产品。环节拆分：内容生产由 Claude Code 的 /yt-repurpose 技能把一条YouTube视频批量改成SEO博客+邮件草稿+图表，Claude 三个档位分工（Opus起草客户可见内容、Sonnet做调研取数、Haiku干机械杂活），GPT 经 Codex 交叉审稿，本人只做最终批准；获客靠YouTube加SEO——2026年2月23日至10月11日站内 71% 的谷歌点击来自由视频改写的文章（172篇中92篇源自视频）；售后即SEO客户交付。每月固定成本约 300 美元：Anthropic 200 美元/月加 ChatGPT Pro 100 美元/月，DataForSEO 按量充值 50 美元起、可用两个月以上。单位经济：数字产品 5 月到 10 月中卖了 4 万多美元（主要是技能包），代理客户费金额未披露。复制性是这一条的核心：每条 skill 是一份 markdown SOP，重复迭代了 10-20 轮才稳定，还配了自动修补 skill 的脚本（同一错误出现三次以上自动打补丁）——这是本篇少数真正把「交给第二个人照着干」落实成文件的案例。卡点：谷歌 SERP 正在被污染（Nozzle 11月3日数据显示 27.6% 的抽查结果页首页被换站），SEO 数据底座越来越不可靠；策略与客户信任仍依赖本人 10 年营销经验，离开两周客户交付会停。[来源](https://ryandoser.com/one-person-business)

**机会点**：多数一人公司缺的不是模型而是「把自己手艺写成skill」这道工序，可以做陪跑或付费模板——第一步挑一项目标客户每周重复三次以上的工作，帮他把上下文文件和skill写出来并迭代到稳定。

缺口：代理客户收入金额与客户数未披露。

### 6. 88天做到1.04万美元MRR的solo SaaS完整账本 【交付·1人·5-20万】

业务是面向开发者的工作流SaaS，30 美元/月，88 天从 0 做到 10400 美元 MRR、280 个订阅。环节拆分：开发用 Cursor 加 Claude API 的 vibe coding 方式；托管 Cloudflare Pages、Vercel、Supabase（月成本几十美元级）；支付走 LemonSqueezy 抽佣；获客靠 X 上 build-in-public 更新加技术博客 SEO；售后由本人处理，第 3 个月降到每天约 2 小时。账本完整：第 1 个月靠 45 秒 demo 视频挂预售，48 小时卖出 37 份 50 美元终身卡得 1850 美元，当月总成本仅 85 美元；第 2 个月 164 订阅 4920 美元，API 推理成本 182 美元、通道费 265 美元；第 3 个月成本 340 美元加通道费 545 美元，月净现金流 9515 美元。卡点：上线首日没做数据库连接池，Product Hunt 流量峰值把 serverless 函数打超时——基础设施抗压是单人开发最容易翻车的一环。该条为本人自述，未经第三方审计。[来源](https://sachinsharma.dev/blogs/vibe-coding-to-10k-mrr-full-financial-ledger-2026)

**机会点**：「先预售再开发」这个验证动作本身可以标准化——第一步帮有想法的开发者做45秒demo视频加折扣预售页，48小时内看有没有人掏钱，两周即出结论。

缺口：churn率、支持工单量、退款率未披露。

### 7. 纹身转印图工具：一人团队4.87万美元MRR，增长停摆 【获客·1人·20万+】

业务是把照片或草图转成可打印纹身转印图的AI工具，客户是纹身师，28 美元/月，1800 个订阅，月流水 48700 美元（约 34 万元人民币），2026 年 1 月上线，支付数据经 TrustMRR 验证，团队仅 1 人。环节拆分：交付全自动化（图像生成）；获客靠应用商店加 Pinterest 加 TikTok；成本结构与支持负载未公开。卡点清楚：近 30 天增长仅 +0.9%——商店投流渠道见顶，1800 个纹身师订阅可能已接近这个垂类的自然上限。对照组很有信息量：同为一人团队的开源排程器 Postiz 靠 Reddit 加开源社区做到 44.7 万美元 MRR（13100 个订阅、34 美元/订阅），说明获客渠道的选择（社区口碑 vs 商店流量）直接决定一人公司的天花板。收入经 TrustMRR 支付数据验证，一人团队口径来自其 TrustMRR 列表。[来源](https://theaireceipts.com/one-person-ai-businesses)

**机会点**：无明显机会——垂类已被占住且增长停摆，成本结构不明，贸然进入只会重演渠道见顶；唯一可借鉴的是获客渠道选社区而非商店，但这属于打法而非生意空位。

缺口：成本结构、支持工单量、churn未披露。

### 8. 一人用agent集群维护303个项目的数据库：不挣钱，但省下两个全职 【供应链·1人·未披露】

业务是给 bootstrapped 创业者查加速器、资助、奖学金项目的免费数据库（303 个条目），产品未变现，月流水未披露。环节拆分：数据采集、校验、更新、质检由一组窄职责 agent 分工完成（监控源、验证字段、协调调度），人只在异常点介入；按旧金山人力成本折算，这套维护相当于 1-2 个全职运营（年薪 15-20 万美元），现在压缩成 API 费用加本人监督时间。卡点是本篇最值钱的一段经验：agent 基础设施的失败是静默的——页面结构一变抓取器就空转、校验误报、数据库悄悄漂移，agent 自己发现不了，必须配异常告警和定期人工审计；上下文与状态管理也要专门架构设计。该条为对创始人公开笔记的分析报道。[来源](https://www.onepersonunicorn.co/blog/building-with-an-agent-fleet-solo-founders)

**机会点**：用agent跑业务的团队普遍缺「发现agent悄悄出错」的能力，可以做一套轻量异常监控加人工审计服务——第一步接一个用agent集群的业务方，免费跑一周数据巡检，用抓到的漂移案例换付费。

缺口：月流水未披露（产品免费）。

## 本篇机会点小结

**一、最值得动手的一条**：第 3 条——给二线城市抖店接夜间AI客服。理由：它是本篇唯一把「交付无人化+明确对标人工成本（15600元/月/两人）+65%毛利+2680元/月客单」四个数都亮出来的条目，现金模型最干净；客户是夜里丢订单的女装抖店，第一步免费给一家店跑一周夜间咨询、用首响时长和挽回订单换签约，1-3 个月可验证能否签到 3 家付费店。

**二、被验证的需求**：第 2 条月流水 9231 美元、月广告投入约 4600 美元仍有正毛差；第 7 条 48700 美元 MRR、1800 付费纹身师；第 6 条 10400 美元 MRR、280 订阅、月净现金流 9515 美元；第 1 条月营收约 6274 元、6-8 家商家续费；第 5 条数字产品 5.5 个月 4 万余美元——「一个人跑通一条业务」在国内外都已被反复验证，缺的从来不是需求。

**三、明显的空位**：本篇 8 条里 4 条（第 1、2、4、7 条）卡在获客——第 1 条靠本人地推、第 2 条靠烧钱买量且评分 3.0 推高成本、第 4 条完全没设计获客、第 7 条增长停摆只剩 +0.9%；另有第 8 条指出的空位：agent 静默失败监控几乎没人提供服务。交付端的工具已经过剩，获客端和「发现agent出错」这个环节仍是空白。

**四、本篇结论**：交付环节的无人化已接近完成、单位经济普遍算得过来，一人公司的瓶颈整体前移到了获客与质量监控；谁能把获客做成可复制的渠道或工具、谁能兜住agent的静默失败，谁就拿走这批一人公司的下一轮增量。
