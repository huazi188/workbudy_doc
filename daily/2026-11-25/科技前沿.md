# 第一部分：中国 / China

### 1. 智谱发布GLM-5.4：循环架构以750B参数做到2-3T级智能 【AI·智谱·发布开放】📈
智谱11月24日发布新一代旗舰模型GLM-5.4，首次采用Loop Transformer架构，让7500亿参数基座中的28层共享权重网络循环执行两轮前向计算，在参数量不变的情况下把有效计算深度拉满，官方称智能水平等效2万亿至3万亿参数级模型。模型新增视觉理解，编程能力拓展至视频制作、3D建模、机械设计等「泛Coding」场景，已向GLM Coding Plan全量用户开放并上线ZCode、Trae、WorkBuddy、Qoder等平台，非高峰时段速度最高200 token/s，权重计划以负责任方式开源。同一消息源披露智谱已实现10万卡级国产芯片规模化推理、推理毛利率转正。[来源：品玩/网易](https://www.163.com/dy/article/LCGBI1FG05566WT8.html)、[每日经济新闻](https://www.nbd.com.cn/articles/2026-11-24/4656918.html)

**机会点**：GLM-5.4把代码能力外溢到视频、游戏、CAD建模，做「泛Coding」垂直工具的窗口刚打开——给中小设计团队做一个「自然语言生成机械CAD图纸/短视频成片」的订阅工具，第一步用GLM-5.4的FreeCAD建模演示能力复刻一个垂直场景demo，1-3个月可验证付费意愿。

### 2. 无界方舟开源1450亿参数端侧模型，12GB显存笔记本可离线运行 【AI·无界方舟·开源】📈
无界方舟11月24日前后发布并开源端侧基础模型Edge0-145B，总参数量1450亿，官方称其为全球首个千亿参数端侧原生基础模型，在Hugging Face开放权重，开源3天即登顶Text Generation榜单；配套推理引擎同步开源。12GB显存+20GB内存的PC或48GB统一内存的Mac即可运行，解码速度超过80 token/s，团队实测断网笔记本完成了3D建模、游戏制作和视频生成三个案例。[来源：SegmentFault AI日报](https://segmentfault.com/a/1190000048422310)

**机会点**：千亿级模型可离线跑意味着「数据不出域」的私有部署需求有了新解法——给律所、工厂、医院做Edge0-145B离线私有化部署，第一步在一台12GB显存机器上为一家本地企业跑通合同/工单问答，两周内可拿到第一个反馈。

### 3. 谢晓亮团队无创胚胎遗传检测登《自然·生物医学工程》，单基因诊断准确率接近100% 【生物医药·北大/昌平实验室·论文发表】📈
北京大学、昌平实验室谢晓亮与黄蕾、葛颢团队的scm-LIANTI技术11月24日刊发于《自然·生物医学工程》：仅需胚胎培养液中的极微量游离DNA即可同时评估单基因和多基因疾病风险，无需有创活检。团队纳入29个罕见单基因病家系的191份胚胎培养液样本，277个致病变异判断中220个获得可报告结果，且全部与有创活检对照一致；配套贝叶斯连锁分析算法为每个结果提供置信度分级。该技术已联合北医三院、解放军总医院、亿康医学验证，有望替代临床有创检测。[来源：科技日报](https://www.stdaily.com/web/gdxw/2026-11/24/content_618523.html)

**机会点**：无创PGT进入临床前需要大量回顾性验证与流程改造——生殖医学中心、第三方检验所可与团队/亿康医学合作开展培养液样本检测服务转化，第一步联系一家已入组医保的辅助生殖中心做样本回溯验证，1-3个月可见临床端反馈。

### 4. 西安交大钙钛矿界面策略登《自然》：认证效率27.96%、2000小时衰减不超过5% 【能源材料·西安交大·论文发表】📈
西安交通大学刘宇航团队与国内外合作者设计出MeOTFI、TTFI、BTFI等全共轭甲脒基界面分子，让钝化分子同时参与电子传输，破解了钙钛矿电池「缺陷钝化」与「电荷提取」难以兼得的矛盾，成果近日发表于《自然》。基于该策略的反式钙钛矿太阳能电池取得27.96%认证光电转换效率和27.84%认证稳态输出效率，连续最大功率点跟踪2000小时后仍保持初始效率95%以上，为钙钛矿组件走向长效稳定提供新分子设计路线。[来源：西安交大新闻网/中国科学报](https://news.xjtu.edu.cn/info/1033/236661.htm)

**机会点**：全共轭界面分子是可外包合成、可授权的耗材型创新——材料供应商可与课题组对接BTFI类分子的小批量合成与授权，第一步给一家钙钛矿中试线寄样测试，1-3个月可验证器件端效果。

## 本篇机会点小结

**一、最值得动手的一条**：国内2（Edge0-145B端侧开源模型）的「离线私有部署」——数据敏感的律所、工厂、医院长期被「大模型进不来内网」卡住，如今一台12GB显存机器就能跑千亿参数模型，部署门槛降到万元级。给谁做：区域中小企业与专业机构的私有知识问答。第一步：拿一台普通显卡主机为一家本地企业跑通离线合同/工单问答。验证周期：两周内即可获得对方是否愿意付费的反馈，是本篇启动成本最低、验证最快的实体机会。

**二、被验证的需求**：国内1显示智谱GLM Coding Plan全量用户已转为GLM-5.4、额度提升1.5倍且公司推理毛利率转正（付费模型服务被持续消费）；国内5显示长电科技真实产线已让具身智能机器人跑完试运行全流程（工厂开始为机器人作业腾出工位）；国际9显示亚马逊愿付约75亿美元买模型优化技术与团队（跨硬件优化是已经有人花大价钱的需求）；国际2显示Anthropic按token对PR审查代理直接计费（AI审查已进入收费阶段）。

**三、明显的空位**：国际3——Anthropic的Claude产出了VP≠VNP证明并自我声明「无人类数学家核查」，说明AI数学产出大量涌现但审计环节完全没人承接；国内9——芯明Mercury这类新感知模组发布后，市场上缺少中立对比评测，机器人厂商选型只能听厂商说；国际5——Shirudo开源了但pre-release、部署门槛高（需签名内核+TPM 2.0），重度使用编码Agent的企业几乎没有现成的运行时加固服务可买。

**四、本篇结论**：今天的主线是「AI产出开始被要求可验证」——量子算法要Lean证明、代码合并要策略文件、数学成果靠机器核查，验证层正成为AI产业链上新的收费环节；而国内这边，具身智能从展会走进封测厂与船厂，端侧千亿模型把私有部署门槛打到万元级。留在原地的是：AI深伪治理与国际面Grok相关诉讼延续的监管压力，以及Siri式「全自主代理」仍在延期——说了多年还没落地。
