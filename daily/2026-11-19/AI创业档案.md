# 第一部分：大公司 / Established

## 一、资本运作

### 1. Anthropic IPO 定价，最高募资约904亿美元，超额认购10至20倍 【美国·已上市】 📈
Anthropic（代码ANT）于11月18日在美国定价其IPO，发行8.25亿股A类普通股，区间每股70-78美元，基础IPO募资最高约644亿美元，叠加约260亿美元同步私募配售，合计最高约904亿美元；按区间上限计，完全稀释估值约1.4万亿美元。Altimeter CEO布拉德·格斯特纳透露认购超额倍数达10至20倍，并申请50亿美元配售额度，红杉、Iconiq、光速创投、Accel等老股东也计划合计认购数十亿美元。股票预计11月19日在纳斯达克挂牌，将成为史上规模最大的IPO及相关融资交易。([来源：财联社/新蓝网](https://www.cztv.com/newsDetail/917666)、[新浪财经](https://cj.sina.com.cn/articles/view/4047372550/f13e010607201c44y?from=finance))

**机会点**：Anthropic上市后企业级客户与合规需求将公开化，服务商可以做ANT生态的企业迁移与用量审计——第一步筛出招股书披露的1.19万家年付10万美元以上客户中的行业分布，先给中小型企业客户做「上市后合同/定价变动」的影响评估。

### 2. 智谱拟购回H股，据传建设万卡级算力集群试运行 【中国·已上市】 📈
智谱（02513.HK）11月17日公告拟根据一般授权购回H股，11月18日盘中一度涨超8%报363.6港元。另据新浪财经报道，上海浦东黎明智算中心启动算电协同试点，据传为智谱建设万卡级算力集群（设计总功率18兆瓦、国产算力混合配置+绿电直供），目前基本落成进入试运行，智谱未予置评；该公司此前7月配售募资约40亿美元、9月再融50亿美元用于算力扩容。([来源：新浪财经](https://finance.sina.com.cn/jjxw/2026-11-18/doc-inizcrpf4913045.shtml))

**机会点**：国产算力集群密集落地，算力采购决策复杂，可以做国产芯片集群的选型测算与算电协同评估服务——第一步针对「18兆瓦级」园区算电协同做一份公开测算报告引流到B端咨询。

> 资本运作板块其余说明：TSMC 董事会批准最多10亿美元投资 Anthropic 与 OpenAI 的事件公告于11月10日，超出本篇48小时覆盖窗口，不再单列。

## 二、收入与盈利

### 3. 英伟达单季营收首破千亿美元，上调2028财年增速至75% 【美国·已上市】 📈
英伟达11月17日盘后公布2027财年第三财季（截至10月25日）业绩：营收1158.44亿美元，同比增长103%、环比增长20%，首次单季破千亿美元；GAAP净利润652.87亿美元，同比增长105%；数据中心收入1076亿美元，同比增长110%，占总营收约93%，其中超大规模云厂商贡献601亿美元。第四财季指引1300亿美元（±3%），并将2028财年营收增速预期从约70%上调至约75%；新一代Vera Rubin NVL72已开始出货，公司称创史上最快产品爬坡纪录。([来源：每日经济新闻](https://www.nbd.com.cn/articles/2026-11-18/4650963.html)、[财联社](https://www.cls.cn/detail/2537475))

**机会点**：Vera Rubin 平台快速爬坡意味着迁移与适配需求集中爆发，可以做新旧代际GPU的推理成本基准测评与迁移工具——第一步用公开模型做 Rubin 与上代卡的性价比基准榜，向算力租赁商和AI云售卖适配服务。

### 4. Anthropic 招股书：Q3营收170亿美元，大客户超1.19万家 【美国·已上市】 📈
Anthropic 于11月17日更新的招股书（S-1/A）披露：2026年Q3营收170亿美元，为上年同期14亿美元的约12.3倍，前三季合计332亿美元；Q3经营亏损5.67亿美元（Q2曾实现经营盈利9.74亿美元）；年付10万美元以上的客户超过11900家，承诺支出总额9010亿美元（其中707亿美元在12个月内到期），持有现金及短期投资1318亿美元。([来源：Anthropic招股书/Midgard整理](https://www.midgardfinance.com/research/anthropic/?ref=bsky))

**机会点**：Anthropic 客户结构（1.19万家大客户、人均年付）验证了「企业级AI落地」付费的真实性，围绕其企业客户做Claude接入咨询、用量优化与合规审计是直接可切入的服务——第一步找3家已采购Claude API的中型软件公司做用量审计报价。

### 5. 中国大模型「涨价仍量价齐升」：智谱上半年收入9.54亿元 【中国·已上市】 📈
据亿欧11月17日报道，智谱2026年上半年收入9.54亿元，同比增长近400%，其中开放平台及API收入8.25亿元、涨幅约27倍；其编程订阅2月提价30%起、API均价较年初提高约101%，但编程套餐调用量反较年初增长超23倍。MiniMax 上半年收入1.17亿美元，同比增长283%。但资本市场对大模型重新定价：智谱市值从巅峰1.33万亿港元回撤超85%。([来源：亿欧/网易](https://www.163.com/dy/article/LBTKVVG805118K7K.html))

**机会点**：API结构性涨价（DeepSeek峰谷定价涨2.3-4.5倍）使企业推理成本管理成为刚需，可做跨厂商API价格监控与峰谷调度工具——第一步抓取智谱/DeepSeek/MiniMax公开价目做一个「同一任务最低成本」对比页。

### 6. LOBO AI-API 上线约4个月累计收入超300万美元 【中国·已上市】 📈
纳斯达克上市的 LOBO Technologies（LOBO）11月17日公告：其AI大模型API服务自7月28日上线以来累计收入超过300万美元，采用按量计费的轻资产模式；同时其AI养老SISaaS平台（网页+微信小程序「益康哦啦」）提前近一个月上线，面向社区与居家养老场景。([来源：Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/lobo-launches-ai-powered-sisaas-142500909.html))

**机会点**：小公司靠API封装在4个月做到300万美元收入，证明「轻量API+垂直场景出海」路径仍可复制——第一步选一个被验证的垂类（如客服或养老语音）封装成行业API做英文市场投放。

## 三、组织与人事

### 7. 英伟达董事会明确无意黄仁勋复职，启动正式CEO遴选 【美国·已上市】 📉
11月17日财报电话会上，英伟达首任董事长哈维·琼斯表示董事会一致接受黄仁勋辞呈、无意让其复职，已聘请海德思哲在内、外部同步遴选正式CEO；黄仁勋同日发表卸任后首份公开声明，承认个人错误并表示若符合公司与股东利益愿意回归。公司还宣布设立国家安全与出口管制监督委员会。自10月股价高点以来英伟达累计下跌约35%，市值一度跌破4万亿美元。([来源：网易](https://www.163.com/dy/article/LC2B56860530RTB0.html)、[腾讯新闻](https://news.qq.com/rain/a/20261118A07T9I00))

# 第二部分：初创公司 / Early-Stage

## 一、融资

### 8. Genesis AI 完成5亿美元A轮，估值35亿美元 【美国·A轮】 📈
机器人初创 Genesis AI 于11月17日前后宣布完成5亿美元A轮，投后估值35亿美元，由 Premji Invest、Khosla Ventures 与 Eclipse 联合领投。公司同时开发通用机器人和控制机器人的AI软件（物理AI通用基础模型），是目前A轮阶段最大规模之一。([来源：Startup Corners](https://startupcorners.com/digest/funding-digest-2026-11-18))

**机会点**：机器人基础模型融资密度极高，应用层空位明确——不做模型、做「基础模型+具体场景」的集成商，第一步跟踪其SDK/API发布节奏，选一个仓储或巡检场景做首个演示项目。

### 9. 斯坦福双教授创办 Noeri，带1.1亿美元出 stealth 【美国·初创】 📈
斯坦福教授 Carlos Guestrin（XGBoost作者）与 Yejin Choi 创办的 Noeri 于11月16日公开亮相，获1.1亿美元启动资金，Menlo Ventures 领投，Madrona、NEA、Snowflake、Cisco Ventures 等参投。产品是「会自我改进的企业AI系统」：持续监控业务数据与人工反馈，自动生成提示词改写、模型替换等优化提案并走人工审批流程；其源自斯坦福微生物实验室的案例显示，蒸馏后的小模型在特定任务精度超过GPT-5且免付API费用。([来源：AINewsTodays](https://ainewstodays.com/noeri-launches-with-110m-to-build-self-improving-ai-systems))

**机会点**：企业已部署的静态AI管线普遍缺乏持续优化能力，可先以「存量管线体检+蒸馏降本」服务切入——第一步给1家有API账单焦虑的企业做小模型替代POC，2-4周内验证可省成本比例。

### 10. 交大系观壹智能完成首轮数亿元融资，做生命科学基础模型 【中国·种子轮】 📈
生命模型智能公司观壹智能（OneX Intelligence）宣布完成首轮数亿元融资，IDG资本领投，创世伙伴创投、沄柏资本、交大菡源资产、云启资本跟投，棕榈资本担任FA。公司由上海交通大学王延峰教授发起，谢伟迪任CEO兼首席科学家（10月31日刚获首届世界顶尖科学家奖「青年科学家奖」），目标是构建理解生命过程的基础模型，资金用于基础模型研发、湿实验平台建设与产业合作验证。([来源：36氪/投中网](https://36kr.com/p/4074635892872066))

**机会点**：生命科学AI在国内融资升温但产业验证稀缺，有湿实验能力的团队可承接模型公司的产业验证合作——第一步联系模型公司提供「模型预测+湿实验复验」的打包验证服务。

## 本篇机会点小结

**一、最值得动手的一条**：本篇若只做一件事，选第4条背后的「Claude 企业接入与用量优化服务」。依据是 Anthropic 招股书披露的硬数据——年付10万美元以上客户超1.19万家、前三季营收332亿美元——说明企业级AI落地付费已被大规模验证；而 Anthropic 刚上市（第1条），定价、合同与用量政策将进入公开市场审视期，企业客户需要外部专业支持。给中型软件/专业服务公司做 Claude API 用量审计与降本咨询，启动成本万元级（一套审计脚本+测试环境），2周内可用第一份审计报告验证付费意愿。

**二、被验证的需求**：第4条（Anthropic 前三季营收332亿美元、1.19万家大客户）证明企业AI订阅真实付费；第5条（智谱API涨价101%仍量价齐升23倍、收入9.54亿元）证明国内推理侧同样在涨价且需求刚性；第18条（Kindo 收入增长约800%并融资3000万美元）证明企业Agent治理是已收钱的品类；第15条（博川数据5000万元Pre-A轮由产业方参投）证明具身智能数据供给有真实订单基础。

**三、明显的空位**：第3条 Vera Rubin 平台史上最快爬坡，但新旧代际GPU的推理成本基准与迁移工具尚未出现权威第三方；第9条 Noeri 验证了「存量AI管线自优化」需求，国内尚无对标的轻量服务；第14条 Marble 的餐厅后厨AI OS 在国内基本无人做，人员调度密集的连锁业态是现成空位。

**四、本篇结论**：本篇说明AI行业资金正在两端收敛——一端涌入「模型×物理世界/垂直行业」的重资产方向（机器人、生命科学、数据管线），一端涌向已被付费验证的企业级安全与落地服务；而消费级通用应用（Character.AI、Ollie）持续出局，纯功能型产品留在原地，独立公司要么绑巨头生态、要么退到巨头不做的脏活场景。
