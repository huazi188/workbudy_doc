## 一、大模型与产品

### 1. OpenAI发布GPT-6.2 Astra与Sol双模型，旗舰降价20%🔥 全网热议【大模型】

当地时间11月17日，OpenAI正式发布GPT-6.2 Astra（旗舰）与GPT-6.2 Sol（日常高效）两款模型，Astra的API输入/输出定价为每百万词元8/40美元，较GPT-6 Astra下调20%，缓存输入价格下降60%至0.40美元；Sol维持2/10美元不变。官方称Astra在多步骤专业工作基准Agents' Last Exam上较上代提升5.2分、单任务成本不足上代三分之一，较Anthropic Claude Fable 5.2高出5.5分而成本约为其5%；两款模型同步加强网络安全「关键级」限制。业界解读为面对Fable 5.2与Gemini 4 Carbon竞争、把竞争刻度从「谁更强」换成「每任务多少钱」的反击（[界面新闻](https://www.163.com/dy/article/LC0ION540534A4SC_pdya11y.html)）。

**机会点**：旗舰单任务成本降到原来的三分之一，中小团队第一次用得起旗舰Agent——第一步选一个高频行业流程（如合同初审、财报解读），用GPT-6.2做成按次计费的垂直Agent，2周内即可用真实客户验证付费意愿。

### 2. 微软Ignite发布7款自研MAI模型，直接对标Claude定价【大模型】

11月17日微软在Ignite大会一次性发布7款MAI自研模型，覆盖编程、安全、图像与语音，其中MAI Code 2与Code 2 Flash已在GitHub Copilot全面可用：官方称其编程能力达Claude Opus 5.5的96%而价格仅5%、达GPT-6.1 Sol的98%而价格40%。微软不再只做OpenAI能力的转售方，而是在Copilot内建立自己的模型池与定价权，企业还可在Azure内授权权重、用自有数据微调部署（[每日科技情报](http://mp.weixin.qq.com/s?__biz=MzAwOTQyODYxMQ==&mid=2247484765&idx=1&sn=a4bfe36ca1348ebc2adf25acce2bafdc&chksm=9a3c90996b5a4c6246f855f#rd)、[Sift](https://sift.yasint.dev/2026-11-18.html)）。

**机会点**：「96%能力、5%价格」对企业最有吸引力的是存量代码改造——第一步用MAI Code 2给中小软件团队做老项目框架迁移的固定报价试点，按项目收费，1-3个月可验证复购。

### 3. 范式智能发布Phai-A1与Phai-M1，主打本地部署与真人影视视频【大模型】【国产】

11月18日，北京范式智能发布两款自研模型：通用语言模型Phai-A1重点优化推理效率，同等任务响应速度提升约8-10倍，支持原生百万级词元上下文并可在个人电脑本地部署；视频生成模型Phai-M1针对真人影视场景专项训练，支持音画同步生成，瞄准AI短剧等生产链路（[腾讯新闻](https://news.qq.com/rain/a/20261118A0EGR800)）。

**机会点**：数据合规敏感的行业（律所、医院、金融）一直缺「不出内网」的可用模型——第一步给这类客户做Phai-A1在办公电脑上的本地部署POC，主打数据不出域，万元级投入即可验证首单。

### 4. AI办公「工作台」入口之争同日开打，覆盖职业场景成新战场【产品】【国内】

11月16-18日，字节豆包工作上线「工作台」首批覆盖金融、医疗、教育等21个专业场景；腾讯WorkBuddy开放平台披露已覆盖55个专业场景、每日超千万用户合计消耗超100万亿词元；阿里千问办公上线10款模型并开放第三方模型自选。三家的竞争从「统一入口」下移到「谁先占领职业场景」，壁垒正从模型能力转向行业Know-How与工作流沉淀（[新浪财经](https://finance.sina.com.cn/jjxw/2026-11-18/doc-inizensx6769808.shtml)、[每日科技情报](http://mp.weixin.qq.com/s?__biz=MzAwOTQyODYxMQ==&mid=2247484765&idx=1&sn=a4bfe36ca1348ebc2adf25acce2bafdc&chksm=9a3c90996b5a4c6246f855f#rd)）。

**机会点**：三大平台都在抢行业模板与插件供给——第一步挑自己最熟的一个行业，给WorkBuddy或豆包工作台做一套可售卖的垂直模板/插件，上架即验证，2周可看下载与付费数据。

## 二、芯片与算力

### 1. 英伟达单季营收首破千亿美元，盘后涨超4%🔥 全网热议【芯片】【财报】

北京时间11月18日凌晨，英伟达公布2027财年第三财季（截至10月25日）财报：营收1158亿美元，同比增长103%，首次单季突破千亿美元；数据中心收入1076亿美元，同比增长110%，占总营收约93%；GAAP净利润653亿美元，同比增长105%。第四财季指引1300亿美元（±3%）高于市场预期的1252.5亿美元，并将2028财年营收增长目标从约70%上调至约75%，财报后股价盘后一度涨超4%（[网易/第一财经](https://www.163.com/dy/article/LC0J636L0519DDQ2.html)）。

**机会点**：英伟达生态持续扩张意味着交付、组网、调优人才缺口继续放大——第一步考下英伟达相关交付认证，承接智算中心部署与调优外包单，1-3个月可验证客单。

### 2. 英伟达确认停止向中国发运H200等获许可Hopper产品【芯片】【出口管制】

财报电话会上，临时CEO科莱特·克雷斯确认英伟达已停止向中国发运获美国政府出口许可的Hopper架构数据中心产品：第三财季此类产品对华销售为24亿美元，第四财季指引不再计入任何对华数据中心收入。此前美方1月放宽H200许可、批准向阿里、腾讯、字节等10家中国企业销售，但北京方面后来收紧了进口审批，约60万块H200积压香港等待许可（[网易](https://c.m.163.com/news/a/LC12ASC80511D6RL.html)、[路透转译](https://www.chadcowan.com/147902947/nvidia-stops-shipping-us-approved-ai-chips-to-china)）。

**机会点**：对华高端供给归零直接利好国产推理算力——第一步把国产芯片（昇腾、昆仑芯、寒武纪）的推理资源打包成「等效替代」小型租赁方案，面向被断供的中小模型团队，1-3个月可验证续费率。

### 3. Vera Rubin开始出货、供应承诺升至3900亿美元，但对新云厂商融资口径收紧【算力】【供应链】

英伟达披露新一代Vera Rubin NVL72平台已量产出货，为公司历史上爬坡最快的产品，已在CoreWeave、谷歌云、Azure、甲骨文云、Nebius等处运行；截至季末供应承诺升至3900亿美元（上季2790亿美元），各项承诺总额5180亿美元，最高担保敞口约1180亿美元。同时公司明确收紧对新兴云厂商（Neocloud）的供应链融资：不再在建设期提供数据中心担保，只在设施就绪后启动，延期则担保自动失效（[网易/证券时报](https://www.163.com/dy/article/LC0RDKIK053469RG.html)）。

**机会点**：担保新规让新云厂商的履约风险首次成为可量化的信息差——第一步整理一张主流Neocloud的担保状态、履约与融资条件对照表，卖给需要采购长期算力的企业客户，万元级即可启动。

### 4. 国产E级超算「灵晟」蝉联全球TOP500榜首，领先第二名约21%【算力】【国产】

11月17日，SC26国际超算大会发布新一期TOP500榜单：部署于国家超级计算深圳中心的「灵晟」以2.198 EFLOPS的Linpack双精度实测性能蝉联第一，领先美国El Capitan约21%，并以22 PFLOPS保持HPCG榜首；系统实现从芯片、网络、存储到系统软件的全栈自主，已支撑22项千万核级应用（[每日科技情报](http://mp.weixin.qq.com/s?__biz=MzAwOTQyODYxMQ==&mid=2247484765&idx=1&sn=a4bfe36ca1348ebc2adf25acce2bafdc&chksm=9a3c90996b5a4c6246f855f#rd)）。

**机会点**：E级超算的算力需要「会用的人」才能变现——第一步联系深圳超算中心，谈一个行业应用（如气象、材料模拟）的移植试点，把通用算力做成行业解决方案再转售。

## 本篇机会点小结

**一、最值得动手的一条**：四3「Agent沙箱与越权检测工具」。加州起诉OpenAI把「智能体越权/失控」第一次变成执法对象，而几乎每家部署Agent的企业都拿不出安全证明；给企业做上线前的Agent越权扫描与安全报告，客单清晰、竞品稀少。第一步：复现公开沙箱逃逸案例做成检测Demo，找3家已部署Agent的企业免费扫一轮换案例背书；万元级启动，1-3个月可见首个付费单。

**二、被验证的需求**：真金白银已经流出的位置很清楚——一1（OpenAI把旗舰单任务成本压到不足上代1/3，价格战本身就是需求证据）、三1（Anthropic前9个月营收332亿美元、同比增约1206%，认购6-7倍，企业确实在为Claude付费）、三3（百度GPU云收入同比增191%、MaaS词元调用收入增1159%，算力消耗在真实发生）、五4（星动纪元在广东邮政八城11节点常态化供件超1500件/小时，物流客户已按产线规模付费用机器）、五3（Genesis AI拿5亿美元A轮、估值35亿美元，资本在为机器人数据与灵巧手下注）。

**三、明显的空位**：一4（三大工作台都缺高质量行业模板，供给端几乎空白，谁先上架谁吃流量）；二3（英伟达收紧新云厂商担保后，「谁的算力承诺靠谱」没有公开对照表，采购方只能盲选）；五1/五2（工信部标准刚落地，第三方按L0-L5分级的测评认证还没有成熟机构占位，工厂想买机器人但没有验收依据）；四1（90天补办许可倒计时下，中企海外算力合同的合规审查服务还没人系统化做）。

**四、本篇结论**：过去48小时整个行业在从「拼跑分」转向「拼单价、拼交付、拼合规」——模型降价、财报天量、机器人标准与监管新规同时落地，钱和能力都在往能被验收、被计价的环节集中；还留在原地的是「跑分叙事」和没有验收标准、没有ROI凭证的粗放算力与采购。
