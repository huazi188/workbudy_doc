# 第一部分：国内 / China

## 一、收入里程碑

### 1. 编剧转型独立开发，Laper 发布 6 个月做到月入约 35 万元 【中国·1人】📈

前编剧赵纯想听美团联合创始人王慧文一句「为什么不结合你自己的经历做一个 AI 产品」后，停掉手头项目，把自己的编剧本行痛点做成 AI 产品 Laper，一年后月收入约 5 万美元（约 35 万元人民币），收入数据经 TrustMRR 的 Stripe 直连核实，数据截至 2026 年 10 月 31 日。这条案例最干净的地方在于因果链：懂行的用户 → 同行真实痛点 → 用 AI 把开发成本压到极限 → 用户用钱投票。[来源：独立开发前线](https://indiefront.cn/articles/cmvxgaoaj001g9zqcddya4ss7)

**机会点**：垂直职业人群的 AI 工具仍是空位——每个人的本行里都有一份「只有自己知道的苦差事清单」。第一步：列出自己行业每周最耗时的 3 件事，找 10 个同行验证是否有人愿意每月付钱，再动手写代码。

### 2. 先接车企 30 万元订单，再辞职单干工业智能体 【中国·1人】

苏州「n 维」的模式是先以朋友身份帮企业「手搓」工业智能体，某车企付 30 万元买下方案后他才辞职单干——先有客户、再有公司，避开了 1600 万家一人公司整体存活率不足 10% 的生死线。该案例被 2026-11-13 发布的《SOLO BUSINESS·一人公司情报》第 3 期引用（引自人民网/新华社相关报道口径）。[来源：微信公众号 SOLO BUSINESS·一人公司情报](http://mp.weixin.qq.com/s?__biz=Mzg4NTIwMjI3Ng==&mid=2247483812&idx=1&sn=babe2105b911dc760fb9fffad7634335&chksm=ce8f6c36095a0acea5b21ff183f4c7d9992f308d6991dfd79bf1d75eee37a386ac2029358ae9#rd)

**机会点**：制造业企业的「手搓智能体」定制需求真实存在且客单价高（单车 30 万元）。第一步：给 1 家本地制造企业做一次免费的流程诊断，把最费人力的环节做成报价单。

## 三、工具与工作流

### 3. 一人公司的 AI 工具箱：Claude Code 当主力、Codex 当第二工程师 【中国·1人】

独立开发者 Alina 公开自己一个人经营公司、写内容、做 AI 产品（AI 霖子、AI 数字分身等）每天真实在用的工具清单：没有技术团队，用 Obsidian 分层管理知识（AI 只读整理过的那一层），Claude Code 负责写代码、改网站、处理逐字稿等大部分执行，Codex 负责并行开发和交叉复查，且同一仓库同一时间只让一个 AI 写；产品端用 Next.js + Vercel + Supabase + Stripe，配图用 GPT 图像模型、配音用 Fish Audio。该页面为持续更新的工具清单（2026 年 11 月在线版本），属创业者自述、未经核实。[来源：AlinaOS](https://alinalinzi.com/uses)

**机会点**：把这套「双 AI 分工 + 知识分层」的工作流整理成可复制的上手指南或模板包，卖给想单人开工的创业者。第一步：写一篇完整的双 AI 协作工作流教程，放公众号和 Substack 测订阅与付费转化。

## 四、失败与转身

### 4. 一年心血突然关停：xaisite.com 被上游大模型降维打击 【中国·1人】📉

一位国内独立开发者没有预热、没有倒计时，直接在站内挂出公告宣布关停运营约一年的个人项目 xaisite.com，原话是「底层大模型随手一次更新，或者上游一变动，熬夜做出来的功能就被降维打击」；公告未披露用户量与收入等具体数字，作者同时坦承矛盾心态：既怕被淘汰，又忍不住想继续卷。这条公告的价值在于把「个人开发者的命脉被上游捏住」这一结构性风险写成了公开文本。[来源：今日头条](https://m.toutiao.com/article/7703056328729707043)

**机会点**：上游依赖风险催生防御性小工具——做一个「模型 API 变更/停服/涨价监控 + 提醒」服务，卖给建在单一上游上的独立开发者。第一步：先免费监控主流模型的 API 文档与价格页变更，积累订阅名单后再收费。

# 第二部分：国外 / International

## 一、收入里程碑

### 5. AI Designer：vibe coding 出来的 UI 设计工具做到 \$8,338 MRR，Stripe 核实 【未公开·1人】📈

独立开发者 Wiz（@bowlcutWiz）用 Cursor（后换 Claude Code）vibe coding 出 AI Designer——把几个词变成可直接交付给编码 Agent 的网站/App 设计，配 MCP 和画布让 Claude Code 直接调用。截至 2026-11-02 经 TrustMRR 的 Stripe 验证为 $8,338 MRR、283 个活跃订阅、近 30 天收入 $9,605；他 2025 年 3 月辞职、此前多个项目只有几百美元收入，2025 年 12 月上线后靠每日公开 MRR、Reddit 高质量发帖冷启动，2026 年 4 月上线 MCP 加每日 SEO 流水线后收入跳涨。[来源：Shipped & Paid](https://shippedandpaid.com/cases/ai-designer-ui-design-tool-8-3k-mrr-vibe-coded-cursor-claude-code)

**机会点**：给编码 Agent 做配套的 MCP 工具是当前最强的单人增长杠杆——凡是被 Claude Code/Cursor 用户高频使用的环节都可插件化。第一步：为自己最熟悉的一个编码流程写一个 MCP 并在 Product Hunt 发布，同时用 TrustMRR 公开收入数据。

### 6. X 粉丝不到 100，全靠 Reddit 发帖做到月入 1.7 万美元 【未公开·1人】

Diego Roshardt 一个人做 AppAlchemy——用聊天生成并迭代修改 iOS/Android App 界面的「设计界 Cursor」，在 X 上粉丝不到 100、没有任何社媒资源的情况下做到月收入约 1.7 万美元、付费用户 1000 多个、注册用户 2 万多，推广零广告，用户全部靠 Reddit 发帖拉来；此前他失败过 7 个以上软件产品，第一个版本只花约两周做出。注：原始披露为 Starter Story 2025-07-09 采访，中文圈于 2026-11-11 由哥飞重新拆解讨论。[来源：腾讯网（哥飞拆解）](https://new.qq.com/rain/a/20261111A000NP00)

**机会点**：Reddit「非广告式」冷启动对零粉丝开发者依然有效且免费。第一步：选定目标 subreddit，连续发 10 条纯干货帖建立可信度，再在合适的帖子下自然带出产品。

### 7. HabitKit：一个人做习惯追踪 App，2025 年收入 60.2 万美元 【德国·1人】

德国开发者 Sebastian Roehl 独立开发习惯追踪 App HabitKit，把全部精力压在单一产品上，2025 年单人入账 60.2 万美元、订阅用户 2.51 万（12 月口径 MRR 约 2.8 万美元），靠 $1-2/月的小客单高频续费堆叠，前 2.5 年才爬到 $10K/月、此后增长突然加速，而他的其他 App 几乎零贡献。注：数据为 2025 年口径，2026-11-13 被中文一人公司媒体重新引用披露，创业者自述、未经审计。[来源：微信公众号 SOLO BUSINESS·一人公司情报（引 For You 报道）](http://mp.weixin.qq.com/s?__biz=Mzg4NTIwMjI3Ng==&mid=2247483812&idx=1&sn=babe2105b911dc760fb9fffad7634335&chksm=ce8f6c36095a0acea5b21ff183f4c7d9992f308d6991dfd79bf1d75eee37a386ac2029358ae9#rd)

**机会点**：单点订阅 App 的长线玩法依然成立，但要求接受约 2 年的冷启动期。第一步：选一个自己每天真实使用的高频场景做单点产品，不做 App 矩阵，先跑通第一笔订阅再谈增长。

## 二、产品与打法

### 8. Flibbo：不会写代码，把顶级模型包进一个 App 做到 \$55K MRR、50 万用户 【未公开·1人】

前电商卖家 Sina Sinry 不会写代码，把 Veo 3、Kling 等顶级 AI 模型打包成面向创作者的移动应用 Flibbo，做到 $55K MRR（峰值曾超 $90K）、累计 50 万用户，打法核心是 TikTok 病毒式翻拍（viral remake）内容获客加付费墙 A/B 测试，目标是 2026 年 11 月达到 \$30 万 MRR。他的路径是从卖一次性数字产品转向订阅制「攒资产」，获客不靠投放靠内容循环。[来源：MRR Story（创业者自述，未经核实）](https://www.mrrstory.com/stories/he-built-a-55k-mrr-ai-app-without-knowing-how-to-code)

**机会点**：「病毒式翻拍」内容模板是被验证的获客引擎，但多数小创作者不会量产。第一步：给中小创作者做一套可批量套用的翻拍视频模板/流程，用 TikTok 数据验证 2 周。

### 9. 3D-Agent：Blender AI 插件，12 个月做到 \$6,269 MRR、Stripe 核实 【未公开·1人】

3D-Agent 是一个 Blender AI 插件：用户用自然语言描述需求，AI 直接在用户正在运行的 Blender 里生成可编辑的场景、模型与动画，面向 3D 建模师、建筑师和独立游戏开发者；截至 2026-10-30 经 TrustMRR 的 Stripe 验证 MRR $6,269、238 个活跃订阅，上线 12 个月内累计收入 $29,828，全部收入产生于最近一年。[来源：Agent Money List](https://agentmoneylist.com/category/dev-tools)

**机会点**：专业 DCC 软件（Blender、SketchUp、CAD）的「自然语言 → 操作」Agent 插件是可复制的空位，且插件生态自带精准付费人群。第一步：选一个自己最熟的专业软件写出最小可用插件，公开收入数据建立信任。

## 三、工具与工作流

### 10. 教企业主用 Claude Code 搭「个人 AI 操作系统」 【美国·1人】

Liam Ottley 于 2026-11-12 发布工作流案例：手把手教一位企业主用 Claude 桌面端 + Claude Code 搭建经营公司的「Jarvis」——把公司语境（角色、团队、战略、品牌）整理成文档让 Agent 快速起飞，用 CLAUDE.md 定边界，会话管理用 prime/log/handoff 三个命令替代自动压缩，并讲清 MCP（快但撑大上下文）与 API key 的取舍。这是一人服务企业主的可复制交付样板。[来源：Frontier Models](https://frontiermodels.cc/video/i-built-a-business-owner-his-own-jarvis-with-claude-code)

**机会点**：中小企业主想用 AI 但不会配置，「个人 AI 操作系统」搭建是刚出现的付费服务位。第一步：用现成的 CLAUDE.md + 会话管理模板免费帮 5 个本地企业主搭起来，验证后转收费交付。

### 11. 把 Claude API 包成 GitHub Action：90 天做到 \$8K MRR、毛利 97% 【未公开·1人】

据 The Agent Times 引述 agentincome.io 的汇编案例：一位单人开发者把 Claude API 封装成 GitHub Action，自动为 Pull Request 生成描述，$9/月定价、API 成本低于 $200/月，90 天做到 $8,000 MRR、毛利 97%；同期披露的典型单人 Agent 技术栈为 n8n 编排 + Claude API + Postgres 记忆 + Railway 托管，单产品基础设施成本 $5-15/月。注：创业者自述口径的第三方汇编，未经核实。[来源：The Agent Times](https://theagenttimes.com/agents/article/solo-developers-build-agent-as-a-service-products-hitting-8k-177b6cc1)

**机会点**：Agent 即服务（Agent-as-a-Service）的小订阅模式跑得通，且开发者的重复流程可直接打包上架。第一步：把自己每周重复做的一个开发流程写成 GitHub Action，上架 Marketplace 收费验证。

## 四、失败与转身

### 12. 上线两天即下线：16 岁开发者翻 1165 条差评，把 AI 同事产品推倒重构 【未公开·2人】📉

一位 16 岁开发者与联合创始人花三天做出 AI 同事产品 Tobo，上线两天后因用量额度在不到一天被烧光（4 天烧掉 \$2500）被托管方暂停，当晚删掉产品；随后他们做了件笨事：把 Viktor、Lindy、Dust、Glean 等 7 款同类产品的公开差评全部收集（Reddit、HN、Trustpilot、G2 等，共 1165 条、687 条相关，归入 20 个类别），把每条抱怨转成一条设计约束重构 Tobo——三个反直觉发现是：没人抱怨 AI 笨（答案错误只排第 9）、积分制是最被恨的定价、记忆是可见性问题而非容量问题。团队计划 2026-11-18 申请 Techstars，全程公开构建，差评清单放在 heytobo.com/complaints 与 GitHub。[来源：网易号转载](https://www.163.com/dy/article/LBEMCUUO05561FZQ_pdya11y.html)

**机会点**：「差评挖掘法」本身就能卖——大多数 AI 产品团队没时间系统翻竞品差评。第一步：选一个 AI 品类爬 1000 条公开差评，整理成「抱怨 → 需求清单」付费报告卖给该赛道的创业者。

### 13. favURL：solo 运行半年，宣布 11 月关停并全额退款 【美国·1人】📉

solo 创始人 Valon Badivuku 宣布其产品 favURL（把商家的 Google 评论自动生成展示页）于 2026 年 11 月关停：项目累计生成 622 个页面、覆盖 143 个类目 35 座城市，有真实商家认领并手动编辑，但他两次转型后判断「对 why 的正确不等于 how 可持续」——没有等来共同创始人，而服务器账单和逐条评论的 API 费用不再值得无限期垫付，于是选择体面关停：服务期内全功能保留、所有付费用户无条件全额退款、页面可导出。[来源：创始人博客](https://valon.info/writing/favurl/learn-fast-fail-fast)

**机会点**：无明显机会——自动生成的冷启动页没有所有权感和回访理由，留不住人；同类想法必须绑定商家真实工作流（如收款、预约）而非只做展示层。

### 14. Poppy：一人做 ambient AI 一年多，安静关停 【未公开·1人】📉

Saik 一人运营 Second Nature Computing 超过一年，做「环境感知型 AI」产品 Poppy——上周（11 月初）一条帖子、没有戏剧性，直接把产品下线、公司清算。复盘指出 solo founder 税真实存在：招聘、发薪、报税、营销、投资人关系全部压在一人身上，每次上下文切换都是全量的；而 ambient AI 品类分发极难——用户不会主动搜索它、价值要几周才被感知，获客成本高、口碑传播慢，靠个人积蓄养不起习惯形成所需的时间线。[来源：One Person Unicorn](https://www.onepersonunicorn.co/blog/solo-founder-lessons-ambient-ai-startup-shutdown)

**机会点**：无明显机会——单人做「慢反馈、难搜索」的 ambient 品类在分发上不成立；个人开发者应选即时可见反馈的品类，让第一次使用的价值在 1 分钟内出现。

## 本篇机会点小结

**一、最值得动手的一条**：第 10 条（帮企业主用 Claude Code 配置个人 AI 操作系统）。理由：它不需要写新产品，模板和方法已被 Liam Ottley 于 11 月 12 日完整公开验证，交付对象（中小企业主）付费能力和意愿都高于开发者群体。给谁做：本地有 5-50 名员工、被重复事务淹没的企业主。第一步：拿现成 CLAUDE.md + prime/log/handoff 会话模板免费帮 5 家企业搭起来，两周内可验证是否有人愿意付费托管。

**二、被验证的需求**：第 1 条 Laper 月入约 5 万美元（TrustMRR/Stripe 直连核实）；第 5 条 AI Designer $8,338 MRR、283 订阅（Stripe 核实）；第 9 条 3D-Agent $6,269 MRR（Stripe 核实）——「给专业人群/专业软件做 AI 配套」已有人持续付钱；第 2 条车企 30 万元买定制智能体，证明制造业企业愿意为「手搓」流程自动化付高价；第 12 条证明 687 条真实差评集中指向计费、可见性、可靠性三类痛，AI 产品团队愿意为规避这些坑投入设计。

**三、明显的空位**：第 4 条——国内个人开发者已用一年心血验证了「上游一变就死」的风险，但市面上还没有面向独立开发者的模型 API 变更/停服监控工具；第 12 条——差评挖掘从个人方法变成可交付的报告服务，目前只有 Tobo 团队自己在做，没有第三方把它做成产品；第 8 条——病毒式翻拍获客被 50 万用户验证，但中小创作者缺少可批量套用的模板工具。

**四、本篇结论**：单人 AI 创业正在两极分化——绑定真实付费场景（编剧、承包商、3D 建模师、企业主）的产品在快速冲高收入，而做泛需求、慢反馈、纯展示层的产品在批量关停；今天这个领域里，选择「谁在付钱、痛点多具体」比选择模型和代码能力更重要，而上游依赖风险（第 4 条）仍是所有人头上的共同悬顶之剑。
