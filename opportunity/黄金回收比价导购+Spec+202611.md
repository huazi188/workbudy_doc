## MVP 目标和用户

有闲置金饰的本地消费者使用，正规回收门店为明示导流付费。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 汇总商户许可发布的回收报价，标注成色、称重、服务费、有效期及到店复核口径。

**对照流程** 以逐家电话问价和只显示克价的图文为基线，比较净到手价和过期报价比例。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 同城覆盖一条街区，按克重和成色情景做测算卡，由用户到店核实并留回执信息。

**首轮验收门槛** 5家商户连续10个营业日更新，报价时间戳覆盖100%，抽核20笔同口径报价时差异≤2%。

## 最小权限与异常处理

商户事后加扣费或推广影响排序。统一显示净到手口径，显著标记商业合作和公示变更。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按门店核验展示费或可追溯预约收费，以两店短周期出价和实际有效预约率测算。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
