## MVP 目标和用户

准备换新的消费者使用，家电或汽车经销商可为透明报名提醒服务付费。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 以当地主管部门正式通知生成适用品类、受理入口、材料清单、时间和已核验日期。

**对照流程** 比较轮流咨询客服和从公众号找文件的完成时间、漏看截止日期与错误来源。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 首批仅覆盖同城家电一品类，双人工核验后对比提醒组与旧查询方式的资料备齐率。

**首轮验收门槛** 尝试覆盖2城30条公开条款，测试时官方出处覆盖100%，到期提醒误发0次，20人中≥15人完成准备任务。

## 最小权限与异常处理

政策更新与仿冒申报入口。只提醒去官方渠道，逐城复核日期，保护用户联系方式。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按城市月服务费给商户或透明预约费报价，两商户付费基于有效咨询样本验证。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
