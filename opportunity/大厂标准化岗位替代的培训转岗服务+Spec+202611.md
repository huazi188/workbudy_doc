## MVP 目标和用户

企业人力发展部门或自愿转岗人员采购，运营与研发支持岗位学员使用。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 根据目标岗位任务与授权模拟材料交付AI协作训练、带评分答卷和个人作品复盘。

**对照流程** 对照免费模型教程及人力内部培训，比较限定任务表现、完成度和面试进展。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选有明确招聘任务的运营或测试岗位，用相近难度的前后测和招聘人员匿名盲评分。

**首轮验收门槛** 首期10人完课≥8人，至少6人在同难度任务评分提高≥20%，另追踪30天岗位动向。

## 最小权限与异常处理

就业结果受行业和个人背景影响，公开区分技能验收与就业追踪并取得自愿同意。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按学员或企业班收钱，先测试一班明确授课内容与退款条款的付费报名。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
