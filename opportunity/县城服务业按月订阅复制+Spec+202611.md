## MVP 目标和用户

县城家政、装修或维修店老板采购，前台或负责人处理询盘与报价。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 由客户指定一个合法接入渠道，实现营业时间、服务范围问答和回拨线索登记，输入店主核实的常见问答与服务费区间。

**对照流程** 对比商家原先在高峰和非营业时段的回复时长与有效线索数，逐个对照同类问句。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 先选一个行业的两家店，采前一周基线，首周仅生成草稿，复核通过后逐步开放标准问答。

**首轮验收门槛** 拟一个月记录至少50条经授权询盘，标准问题正确率≥95%，中位首响低于2分钟，复杂报价与争议100%转人工。

## 最小权限与异常处理

误承诺和收集过量个人信息，统一话术、最小字段、敏感事项交接，服务价格由店主确认。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按门店和单渠道包月，客户额外渠道另计，向10家店报固定月费并记录至少2个实付试用。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
