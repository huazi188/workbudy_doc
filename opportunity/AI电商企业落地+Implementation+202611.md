## 2. Phase 1：验证期（8周，2026-11-15 → 2027-01-10）

### 2.1 核心目标

```
商业目标:
□ 完成 15-20 个企业负责人深度访谈
□ ≥ 50% 受访者有签单意向
□ 至少签署 1 份试点协议（付费或低价）

技术目标:
□ 完成 1 家企业完整岗位遍历
□ 交付 20+ 个技能包，客户验收通过
□ 实测人效提升 ≥ 20%

辅助验证（快速入口）:
□ 客服代理在 3-5 家店铺跑通
□ 质检外包在 5 家服饰店铺试点，2 周内看转化数据
```

### 2.2 周度计划

#### Week 1（2026-11-15 to 2026-11-21）：启动准备

**核心任务**:
- 拆解神州控股「捷小果」案例，提炼岗位遍历 SOP
- 建立岗位遍历问卷 V1（20题，覆盖4个核心岗位类型）
- 加入 3-5 个仓配/代运营行业微信群，开始摸排潜在客户
- 在 2-3 个服饰商家群招募质检外包试点（免费/99元/月）

**交付物**:
- 岗位遍历方法论文档 V1（5-8页）
- 访谈问题库（40题，从中选 20题）
- 目标客户名单（首批 30 家）

**成功指标**:
- 完成方法论文档
- 加入 3+ 个行业群，初步识别 10+ 潜在客户
- 质检试点招募 3+ 家意向店铺

#### Week 2（2026-11-22 to 2026-11-28）：访谈启动

**核心任务**:
- 开始企业访谈（目标：本周完成 5-6 个）
- 访谈聚焦：现状痛点 + 付费意愿 + 决策路径
- 质检外包试点启动（开始为 3-5 家店铺做 AI 图片质检）
- 评估 2-3 家免费试点企业意向

**交付物**:
- 访谈录音 + 整理报告（5-6份）
- 质检服务 Checklist（视频/图片审核标准）

**成功指标**:
- 完成 5-6 个访谈
- 初步验证付费意愿（至少 3 人表示有意向）
- 质检试点启动

#### Week 3-4（2026-11-29 to 2026-12-12）：深度验证

**核心任务**:
- 加速访谈（目标：累计完成 15 个）
- 整理访谈报告，提炼关键洞察（付费意愿分布、核心顾虑）
- 确认 1-2 家免费/低价试点企业，签署意向协议
- 客服代理技术调研（Dify + 千问 API 配置测试）

**交付物**:
- 访谈洞察报告（付费意愿、核心顾虑、决策路径分析）
- 试点协议草稿
- 客服代理技术方案文档

**成功指标**:
- 累计 15 个访谈，≥ 7 个（约50%）有明确付费意向
- 至少 1 家试点协议意向确认

#### Week 5-6（2026-12-13 to 2026-12-26）：试点启动

**核心任务**:
- 正式启动第一家试点企业的岗位遍历
  - 聚焦 4 个核心岗位：客服/仓内拣货/内容上新/运营数据分析
  - 完成问卷调研 + 操作录制
- 制作第一批 10 个技能包（客服类 4 个 + 仓配类 3 个 + 内容类 3 个）
- 质检外包第一轮反馈收集（付费转化验证）

**交付物**:
- 4 个岗位的操作分析报告
- 10 个技能包（初稿）
- 质检外包 2 周反馈报告

**成功指标**:
- 技能包初稿完成，提交客户预验收
- 质检外包 2 周复购率 ≥ 50%

#### Week 7-8（2026-12-27 to 2027-01-10）：试点交付 + 评估

**核心任务**:
- 完成 20+ 技能包最终版，通过客户验收
- 配置上线第一个智能体（钉钉或企微）
- 采集 2 周效果数据（人时对比基线）
- Phase 1 总结评估：Go/No-Go 决策

**交付物**:
- 技能包文档（最终版 20+）
- 智能体配置说明书
- Phase 1 效果报告（人时节省数据）
- Phase 2 进入决策文档

**成功指标**:
- 技能包客户验收通过率 ≥ 80%
- 2 周效果数据显示人时节省 ≥ 10%（4 周后预期达 20%）
- Phase 2 决策：GO

## 4. Phase 3：市场验证期（4-6周，2027-03-15 → 2027-04-30）

### 4.1 核心目标

```
□ ARR 达到 500 万+
□ 客户获取漏斗跑通（从内容营销到成单的全链路）
□ NPS ≥ 40
□ 确认 1-2 个高 ROI 获客渠道
```

### 4.2 重点任务

#### 营销策略：内容驱动 + 行业渗透

**内容营销**:
- 核心内容：「企业 AI 落地案例拆解」（双11/神州控股等案例深度解读）
- 渠道：公众号 + 视频号 + 知乎 + 领英
- 节奏：每周 2 篇深度内容 + 每天 1 条短视频
- 获客机制：内容吸引企业负责人 → 免费「岗位 AI 化诊断」获取联系方式

**行业渗透**:
- 聚焦 2 个垂直行业（仓配物流 + 美妆品牌）
- 参加垂直展会：物流展 + 电商运营峰会
- 建立行业 KOL 合作（3-5 个仓配/电商领域 KOL）

#### 销售漏斗设计

```
Top of Funnel:
├─ 内容触达（公众号/视频号/知乎）
├─ 行业展会/峰会露出
└─ 合作伙伴推荐（VC/加速器/供应链服务商）

Middle of Funnel:
├─ 免费「岗位 AI 化诊断报告」（1天交付，价值感知强）
├─ 线下沙龙/闭门会（20人规模，行业负责人）
└─ 试点合同（1-5万的低价入门版）

Bottom of Funnel:
├─ 付费完整服务（15-80万）
└─ 效果分成协议（高价值客户）
```

| 诊断 | 月诊断申请量 | 50+ |

## 8. 风险缓解计划

### 8.1 风险 1：B 端销售周期长

**缓解**: 双线并行
- 线 A（快）：质检外包 + 客服代理（2-4周成单，月费低但验证商业模式）
- 线 B（慢）：岗位智能体完整交付（3-6月成单，高客单价）
- 通过线 A 的现金流支撑线 B 的长周期销售

### 8.2 风险 2：效果计量纠纷

**缓解**:
- 合同中明确基线计算规则（上线前 4 周的平均人时 × 参与岗位数）
- 效果监测数据由第三方系统自动采集（非甲方报告）
- 月度双方确认数据（电子签名存档）
- 分成上限设置（不超过合同金额 3 倍）

### 8.3 风险 3：大厂下场

**缓解**:
- 聚焦方法论和行业经验，而非工具层
- 核心护城河：行业岗位知识库（大厂不会深耕单一行业岗位）
- 与大厂工具形成生态共生（帮企业用好阿里百炼/华为盘古）
- 垂直行业深耕 → 仓配行业前 20 名客户 = 市场领导者

### 8.4 风险 4：团队能力不足

**缓解**:
- Phase 1 验证期只需 2-4 人（创始人 + 工程师）
- Phase 2 通过技能顾问（兼职）降低全职招聘压力
- 行业顾问来源：前供应链/仓配公司高管（有知识 + 有客户资源）

## 9. 决策点和检查清单

### Phase 1 → Phase 2 决策门（2027-01-10）

**必须满足（全部）**:
```
□ 技能包客户验收通过率 ≥ 80%
□ 实测人效提升 ≥ 20%（或 2 周数据显示趋势正确）
□ ≥ 50% 访谈对象有付费意向
□ 至少 1 家付费/低价试点完成
```

**应满足（至少 2 个）**:
```
□ 质检外包 2 周复购率 ≥ 50%
□ 客服代理在 3 家店铺自动处理率 ≥ 65%
□ 获得至少 1 家付费大客户承诺（≥10 万）
□ 技能包第 2 家企业交付时间 ≤ 首次 60%
```

**停止信号（出现即暂停）**:
```
□ 付费意愿访谈 < 20%（市场时机不对，重新评估）
□ 技能包准确率 < 60%（技术路线需调整）
□ 人效提升 < 10%（价值主张不成立，调整产品定义）
```

### Phase 2 → Phase 3 决策门（2027-03-15）

```
必须满足:
□ ARR ≥ 100 万
□ 付费客户 ≥ 3 家
□ 技能包模板库 ≥ 50 个
```
