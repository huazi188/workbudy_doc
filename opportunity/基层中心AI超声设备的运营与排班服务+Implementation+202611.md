# 基层中心AI超声设备的运营与排班服务 · 实施计划

日报 AI硬件落地应用 · 5，机会点表第 34 行，线索表第 15 行（本篇第5条）。  
编制日期 2026-11-28。  

## 启动条件

**HOLD｜补齐证据后评审。** 初筛，信心有限。

首轮限于取得缺失证据、必要的离线样例与准备工作。未关闭关键问题时，现场试点与开发时间表保持待评审。

**范围** 有统一排班责任的医联体牵头医院设备科和社区中心运营主管。  
**待验证问题** 专科医生时段、社区约号和设备维保没有同步，空档与改约增加运营成本  
**首份交付** 用无患者信息的模拟时间表核对社区机位、专家可用时段和停机通知，导出由医院确认的排班台账  
**第一项动作** 用无患者信息的模拟时间表核对社区机位、专家可用时段和停机通知，导出由医院确认的排班台账

## Phase 1｜需求与可行性验证（第 1–8 周）

| 时间 | 负责人 | 任务与可核查产物 |
|---|---|---|
| 第 1 周 | 业务负责人 | 确认采购人、操作人和流程范围，记录近一次真实业务流程。候选切入动作见下文，先取得数据与场地授权。 |
| 第 2 周 | 客户开发 | 确认现行替代、费用、样本获取和采购门槛。建立观察记录并交业务负责人签字。 |
| 第 3 周 | 数据与交付 | 固定样本纳入条件、分母和对照，隔离验证样本。基线与候选流程使用同批或配对样本。 |
| 第 4 周 | 交付与业务 | 执行限定试点，交付结果、失败清单和人工干预记录。 |
| 第 5 周 | 质量负责人 | 复核边界样本、异常恢复、撤销流程及复核成本，记录有效样本不足的分组。 |
| 第 6 周 | 商务或预算负责人 | 提交分项报价，请采购方明确费用、预算科目、签收条件与签署时间。 |
| 第 7 周 | 项目负责人 | 用真实耗时与费用复算单次贡献或内部节省，记录平台、替代供应商和人工路径变动。 |
| 第 8 周 | 业务与质量负责人 | 依据验收和付费记录决定继续、补证或终止。归档报告、范围变更、退出与资料移交记录。 |

日报验证窗口为 **1-3个月**。八周是内部评审窗口。日报为两周时，先完成可行性小样，后续周次只在小样达到质量和授权门槛时投入。日报为一至三个月时，八周内提交中期复核，样本不足时重新约定范围。

**现场验证** 用无患者信息的模拟时间表核对社区机位、专家可用时段和停机通知，导出由医院确认的排班台账  
**验收条件** 对50个模拟约号，冲突和无医生时段全部拦截，排班员用时相对人工下降≥30%，真实场景需获院方正式批准  
**监测和停损** 跨机构数据责任和设备适用范围须由院方审查，试点仅覆盖排班和维护票据。[国家药监局分类界定公告](https://www.nmpa.gov.cn/xxgk/ggtg/ylqxggtg/ylqxqtggtg/20240511175941109.html?type=pc)  
**预算验证** 向医联体测每点位运营服务接受价，按协调人时、机位闲置和停机核算管理收益

第一阶段交付范围与授权记录、基线、样本对照、异常台账、真实报价或预算意见、单位成本与继续或终止决议。决议须能回溯到一条业务输入和一条验收记录。

## Phase 2｜限定开发与交付（第 9–17 周）

启动条件为 Phase 1 的验收、授权和预算已记录。优先交付本次范围内的输入、最小结果、人工复核、验收台账和异常恢复。

| 周次 | 责任 | 工作与完成条件 |
|---|---|---|
| 9 | 业务与技术负责人 | 冻结客户、地点或系统、数据、例外和必备输入，形成签署范围和明确验收人。 |
| 10 | 数据负责人 | 按约定字段接入历史样本，重复执行对账，保留缺失和拒收原因。 |
| 11 | 交付负责人 | 构建最小交付并接入操作步骤，保留现行流程的输入和产物。 |
| 12 | 质量负责人 | 制作验收记录，抽检边界、低频异常与失败样本，判断是否需要补样。 |
| 13 | 技术负责人 | 实现或演练异常暂停、人工复核与回退，记录恢复耗时和责任人。 |
| 14 | 技术与运营 | 按实测任务量核算工具、设备和人工成本，确认处理时效达成条件。 |
| 15 | 业务与质量 | 对冻结样本回测并进行有限现场验证，记录修正和未解决事项。 |
| 16 | 交付与使用者 | 交接配置、接口说明、运行手册、权限和成本明细，完成操作者演练。 |
| 17 | 业务与预算 | 按验收门槛签署结果并核验实际费用，记录需补验的缺项及归属。 |

**场景架构和交接对象** 按工位、批次或工单为样本建台账，保留现行方案输出、候选输出、质检判定、人工干预和可恢复备份。接口由厂方或设备商确认。  
**现场验收** 对50个模拟约号，冲突和无医生时段全部拦截，排班员用时相对人工下降≥30%，真实场景需获院方正式批准

## Phase 3｜市场和复用验证（第 18–21 周）

| 周次 | 责任 | 工作与可验收产物 |
|---|---|---|
| 18 | 商务或预算负责人 | 用首单记录更新报价与交付范围，确认第二个客户或第二个流程的所有人和预算。 |
| 19 | 交付与客户操作人 | 对第二组样本重新验收，计入新增适配工时、周期和人工干预。 |
| 20 | 数据与财务 | 复算实收或节省、复用成本、人工与设备费用、风险留置金和单次贡献。 |
| 21 | 业务与质量 | 对照首个和第二个场景复盘，确认验收结果是否可复制以及是否存在再购或实际持续使用。 |

## Phase 4｜规模化（通过 Phase 3 后）

依据真实需求与交付容量扩展站点、客户或单元。每次扩展验证权限、样本代表性、操作人、干预能力和退出路径。交付、商务和质量共用变更日志与台账，按实际故障、支持工时及续费记录更新服务范围。

## 资源、分工与预算

| 资源 | 交付责任 |
|---|---|
| 业务负责人 | 定义目标、提供现行流程与业务样本、确认采用条件。 |
| 产品或交付负责人 | 控制范围和变更，维护结果、工时、授权、回退及移交记录。 |
| 技术与数据负责人 | 确认依赖和数据，建立基线、接口权限和异常上报。 |
| 质量或专业审核人 | 共同制定纳入条件，复核关键差错、验收和退出操作。 |
| 预算或采购负责人 | 审批分阶段投入、核对报价与入账，保留续做或结束决定。 |

日报预算口径为 **日报未列，取正式报价后审批**。阶段预算按样本、计算或设备、对接、人员、复核和退出成本分项获批。首单核价依据如下。向医联体测每点位运营服务接受价，按协调人时、机位闲置和停机核算管理收益

## 风险、监测与处置

| 风险 | 触发条件与行动 |
|---|---|
| 业务场景 | 跨机构数据责任和设备适用范围须由院方审查，试点仅覆盖排班和维护票据。[国家药监局分类界定公告](https://www.nmpa.gov.cn/xxgk/ggtg/ylqxggtg/ylqxqtggtg/20240511175941109.html?type=pc) |
| 验收偏差 | 样本分组或基线缺失时暂停解释效果，补齐相同口径后重跑。 |
| 数据及接口 | 关键输入不可取得、权限错误、接口无法稳定复用时缩小范围或恢复现行流程。 |
| 交付容量 | 人工复核、接入与返工超过批准投入时，按实际工时重算报价和交付量。 |
| 采购和复制 | 买方无法承诺预算或第二场景未达门槛时停止扩张，由负责人记录重启所需证据。 |

## 决策与检查清单

- [ ] 获得目标买方、使用者和数据负责人确认，并登记范围与权限。
- [ ] 留档基线、样本规模、异常样本、复核规则、单次成本和验收门槛。
- [ ] 执行限定试点。用无患者信息的模拟时间表核对社区机位、专家可用时段和停机通知，导出由医院确认的排班台账
- [ ] 达到业务和质量门槛。对50个模拟约号，冲突和无医生时段全部拦截，排班员用时相对人工下降≥30%，真实场景需获院方正式批准
- [ ] 取得可核对的付费、合同或内部预算审批，并确认回退与资料交接。
- [ ] 由业务与质量负责人签署继续、补证或终止决定。

出现关键事故、无授权输入或影响一线正常工作时，立即暂停并恢复既有流程。是否重启由负责人核对具体原因、解决条件、样本和批准记录后决定。
