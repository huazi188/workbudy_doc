## 产品定义与用户

**GO｜启动需求与付费验证。** 初筛，信心有限。

| 角色与场景 | 需求 |
|---|---|
| 采购人和使用者 | 200个SKU以内的一人电商店主自行采购并操作 |
| 现有任务 | 重叠订阅吞毛利，公开教程教装工具却很少算账或迁移旧流程 |
| 首单范围 | 试售299元的一次开通和订阅去重包，含一种描述草稿流程及账单月报 |
| 当前基线 | 重叠订阅吞毛利，公开教程教装工具却很少算账或迁移旧流程 |

业务负责人维护样本和验收口径，系统或数据负责人确认接口和使用范围，交付负责人负责运行、异常回收和交接。首单只覆盖试点约定的场景与输入，扩展能力进入后续评审。

## 功能规格

| 优先级 | 功能 | 可核查输出 |
|---|---|---|
| P0 | 场景输入及基线登记 | 适用条件、有效样本数、现行结果、数据与访问授权记录。 |
| P0 | 交付最小可用结果 | 记录5家店调整前一月账单与5项重复任务，配置后复测耗时及次月真实账单并收款 |
| P0 | 人工复核、异常及回退 | 过早取消订阅造成自动化中断，先导出备份、并行跑订单通知，商家自行持有账号 |
| P0 | 对照报告 | 记录版本、输入或样品标识、测试前后结果、复核人和成本核算。 |
| P1 | 更新和复用 | 在首批达标后测试二次更新或新的合格客户，派单前复核适用范围。 |
| P2 | 扩容 | 依据使用频率、维护投入和签约情况评审批量接入、自动化和报表权限。 |

## 成功指标与验收

**场景门槛** 建议至少3家付费、可取消重复订阅或每周节省≥2小时、每店交付≤90分钟，无备份或关键通知丢失就回滚

| 验收项 | 测量与交付物 |
|---|---|
| 覆盖与质量 | 事先定义分母和例外。按约定分层对照，报告无效样本、分组误差和差错根因。 |
| 采用与响应 | 用实测任务量、端到端耗时、人工干预次数和回退耗时记录采用成本，验收阈值由买方在首轮执行前签认。 |
| 商业 | 以实际付款、内部预算签署、试点转正式、再购或续期为指标。收入留档与工时表应能对账。 |
| 停止 | 关键授权缺失、关键质量门槛未达到、出现超出可控范围的异常或预算方拒绝承诺后暂停扩展。 |

同一样本由同一口径比较两种流程。保留基线、候选结果、允许的异常、安全回退和损失记录。评价人在交付结果冻结后复核。低频关键异常按单列出，由业务负责人判断是否须用更多历史资料复验。

## 商业模式与财务

试售299元的一次开通和订阅去重包，含一种描述草稿流程及账单月报

启动成本按日报口径为 **千元级**，正式报价由人力、数据或设备、计算、复核、部署与支持分项汇总。一次性费用按验收里程碑确认，经常性收入只计仍有效的复购或服务合同。错估的接入、返工和客户支持费用逐项补入单位贡献，年度预测按首单工时和签约价格重新测算。

## 技术架构和运维

账单和任务清单、店主自有账号与店铺字段、商品规格人工复核及交接资料

| 模块 | 接口与验收要求 |
|---|---|
| 采集 | 确定输入所有者、来源、主键、时间范围和权限。读取失败记录原因与重试条件。 |
| 处理 | 记录规则或组件版本，输出附可核对的来源、场景边界、拒绝原因或异常标记。 |
| 复核 | 审核人可接收、退回或按现行流程处理。变更记录负责人和时间。 |
| 台账 | 保存指标分母、验收样本、人工覆盖、费用及回退记录，约定访问控制及留存期限。 |
| 上线与退出 | 先离线小样，按决策进入有限试点。交接应有运行手册、已知问题、回退演练和数据处置记录。 |

数据、软件或设备的选型以预试能否达到验收条件及接口适用范围为准。变更涉及预算与上线的，由对应责任人确认。

## Go/No-Go 标准

**GO｜启动需求与付费验证。** 初筛，信心有限。

首轮仅安排需求与可行性验证。开始限定现场试点前，由业务负责人签署范围与验收阈值。

满足场景门槛、出现可核查预算信号并确认接入和退出成本后，可提交下一阶段评审。临界结果先补样本，关键错误需定位并重测。证据及适用边界无法明确时，保留记录，按原流程运行。首步为「记录5家店调整前一月账单与5项重复任务，配置后复测耗时及次月真实账单并收款」
