# 上线后按月巡检订阅 · 产品规格

日报 FDE中小企业落地 · 1，机会点表第 22 行，线索表第 9 行（本篇国内第1条）。  
编制日期 2026-11-28。  

## 产品定义与用户

**GO｜启动需求与付费验证。** 初筛，信心有限。

| 角色与场景 | 需求 |
|---|---|
| 采购人和使用者 | 已上线排产工具的小型五金厂长和计划主管 |
| 现有任务 | 规则变动和插单造成方案异常，缺少定期复盘时员工回到手工排产 |
| 首单范围 | 为三家已上线客户提供每月一次规则和数据巡检，复盘插单、失败队列和人工改动，交付调整清单和复测结果 |
| 当前基线 | 工厂计划员自行更新规则、原集成商按次售后、改买MES排产模块 |

业务负责人维护样本和验收口径，系统或数据负责人确认接口和使用范围，交付负责人负责运行、异常回收和交接。首单只覆盖试点约定的场景与输入，扩展能力进入后续评审。

## 功能规格

| 优先级 | 功能 | 可核查输出 |
|---|---|---|
| P0 | 场景输入及基线登记 | 适用条件、有效样本数、现行结果、数据与访问授权记录。 |
| P0 | 交付最小可用结果 | 为三家已上线客户提供每月一次规则和数据巡检，复盘插单、失败队列和人工改动，交付调整清单和复测结果 |
| P0 | 人工复核、异常及回退 | 规则维护依赖原开发商，且部分客户可能已有等价售后服务 |
| P0 | 对照报告 | 记录版本、输入或样品标识、测试前后结果、复核人和成本核算。 |
| P1 | 更新和复用 | 在首批达标后测试二次更新或新的合格客户，派单前复核适用范围。 |
| P2 | 扩容 | 依据使用频率、维护投入和签约情况评审批量接入、自动化和报表权限。 |

## 成功指标与验收

**场景门槛** 两个月内至少两家签付费巡检，工单可复现率≥90%，客户确认处理的异常中重复出现率较前月下降

| 验收项 | 测量与交付物 |
|---|---|
| 覆盖与质量 | 事先定义分母和例外。按约定分层对照，报告无效样本、分组误差和差错根因。 |
| 采用与响应 | 用实测任务量、端到端耗时、人工干预次数和回退耗时记录采用成本，验收阈值由买方在首轮执行前签认。 |
| 商业 | 以实际付款、内部预算签署、试点转正式、再购或续期为指标。收入留档与工时表应能对账。 |
| 停止 | 关键授权缺失、关键质量门槛未达到、出现超出可控范围的异常或预算方拒绝承诺后暂停扩展。 |

同一样本由同一口径比较两种流程。保留基线、候选结果、允许的异常、安全回退和损失记录。评价人在交付结果冻结后复核。低频关键异常按单列出，由业务负责人判断是否须用更多历史资料复验。

## 商业模式与财务

用原按次售后账单和巡检工程人时核算月费，分别测试标准巡检和含调整工时服务的购买率

启动成本按日报口径为 **万元级**，正式报价由人力、数据或设备、计算、复核、部署与支持分项汇总。一次性费用按验收里程碑确认，经常性收入只计仍有效的复购或服务合同。错估的接入、返工和客户支持费用逐项补入单位贡献，年度预测按首单工时和签约价格重新测算。

## 技术架构和运维

按工位、批次或工单为样本建台账，保留现行方案输出、候选输出、质检判定、人工干预和可恢复备份。接口由厂方或设备商确认。

| 模块 | 接口与验收要求 |
|---|---|
| 采集 | 确定输入所有者、来源、主键、时间范围和权限。读取失败记录原因与重试条件。 |
| 处理 | 记录规则或组件版本，输出附可核对的来源、场景边界、拒绝原因或异常标记。 |
| 复核 | 审核人可接收、退回或按现行流程处理。变更记录负责人和时间。 |
| 台账 | 保存指标分母、验收样本、人工覆盖、费用及回退记录，约定访问控制及留存期限。 |
| 上线与退出 | 先离线小样，按决策进入有限试点。交接应有运行手册、已知问题、回退演练和数据处置记录。 |

数据、软件或设备的选型以预试能否达到验收条件及接口适用范围为准。变更涉及预算与上线的，由对应责任人确认。

## Go/No-Go 标准

**GO｜启动需求与付费验证。** 初筛，信心有限。

首轮仅安排需求与可行性验证。开始限定现场试点前，由业务负责人签署范围与验收阈值。

满足场景门槛、出现可核查预算信号并确认接入和退出成本后，可提交下一阶段评审。临界结果先补样本，关键错误需定位并重测。证据及适用边界无法明确时，保留记录，按原流程运行。首步为「为三家已上线客户提供每月一次规则和数据巡检，复盘插单、失败队列和人工改动，交付调整清单和复测结果」
