## MVP 目标和用户

拥有大量应收对账人工工时的批发商财务负责人采购，出纳与对账员使用。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 从授权销售单、借记项与回款表生成匹配建议、未勾稽台账以及解释字段。

**对照流程** 对照Excel固定模板和现有ERP对账，比较月末差异处理工时和重复人工校验次数。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 挑一个地区业务单元、一种收款渠道，先测两个完整账期的差异台账。

**首轮验收门槛** 100笔脱敏历史交易匹配正确率≥95%，无法确认项全部纳入待审核，自动核销0笔。

## 最小权限与异常处理

部分到账和跨期回款容易误配，金额及期间设硬限制，实际核销走原系统审核。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按公司账套收试点费，若获取付费确认再验证可复用部署的维护费用。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 先验证需求，再决定试点**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
