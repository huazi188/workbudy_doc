## MVP 目标和用户

模型采购团队与应用研发主管。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 版本快照、实测数据集及任务级排名。

**对照流程** 与公开榜单比较同一业务任务失败率和人工补救。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 固定首个行业与三类任务，记录三次运行差异和成本。

**首轮验收门槛** ≥50项任务，每项运行3次，关键结果复现率≥90%。

## 最小权限与异常处理

榜单受提示词和版本影响，公开口径和日期。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

基础榜单免费，销售私有任务复测，争取首份订单。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
