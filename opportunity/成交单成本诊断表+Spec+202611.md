## MVP 目标和用户

装修、健身等本地服务企业的门店老板或市场主管采购，接待和销售团队回填成交节点。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 把经授权的脱敏来电元数据、投放及订单出口做成线索、报价、成交与退款的来源对照表。

**对照流程** 与平台线索单价比较，计算实际成交单成本和可核验的渠道归因覆盖。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选择两个可分渠道的业务，复查来电、到店、付款及取消时间戳，计算各渠道净成交成本。

**首轮验收门槛** 90天数据至少核对50条线索，已付款订单核对一致率≥95%，来源缺失逐行单列。

## 最小权限与异常处理

电话及报价记录涉及个人信息，销售回填也可能偏差。仅用散列标识和必要字段，抽核回款。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按门店和90天账期收费，用同店签后续月度观察单验证复购。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
