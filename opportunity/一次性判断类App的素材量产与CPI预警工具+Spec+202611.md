## MVP 目标和用户

单用途订阅App的独立开发者和素材投放员。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 20条授权版素材、按素材归因的CPI阈值看板。

**对照流程** 与素材助手手动打表比较记录完整和判停延迟。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 同一地区、同受众小样本并行，只验证素材流程和预警。

**首轮验收门槛** 20条全部带可核验的素材标识，达到预设样本数后才判断单条CPI。

## 最小权限与异常处理

小样本误判，限定预算并注明置信区间和判断延迟。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按批收费，向两位有投放预算的开发者开具报价。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
