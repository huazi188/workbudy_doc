## 1. 核心规格

### 1.1 产品定义

**产品名称**: AI导购优化助手（暂定）

**产品定位**:
> 专为电商商家设计的AI导购收录优化服务，帮助高比较成本类目（保健品、母婴、3C、美妆）的商家让其商品更容易被各大电商平台AI导购系统理解和推荐，从AI导购渠道获得增量成交。

**产品形态（Phase 1 MVP）**: 人工服务为主，工具辅助。先验证需求，后产品化。

```
Phase 1: 人工服务（1-3人团队）
  · 人工做参数结构化
  · 工具辅助AI导购收录监测
  · 人工输出优化建议报告
  
Phase 2: 半自动化
  · 自动化收录监测
  · AI辅助参数结构化
  · 人工审核输出
  
Phase 3: SaaS化
  · 商家自助优化工具
  · 自动化全流程
  · 多商家并发服务
```

### 1.2 目标用户画像

**主要用户：电商运营负责人 / 店主**

| 维度 | 描述 |
|------|------|
| **角色** | 保健品/母婴/3C类目电商运营负责人或店主 |
| **规模** | 月GMV 30-500万 RMB |
| **平台** | 抖音/京东/淘宝 至少其一 |
| **团队** | 5-20人 |
| **痛点** | 知道AI导购重要但不会优化，自己尝试无效 |
| **目标** | 增加AI导购渠道的曝光和成交量 |
| **付费能力** | 月费 3000-8000 RMB |
| **决策周期** | 1-2 周 |

**次要用户：电商代运营公司**

| 维度 | 描述 |
|------|------|
| **角色** | 代运营公司的产品/运营经理 |
| **规模** | 管理 10-50 个品牌 |
| **需求** | 批量AI导购优化服务（B2B采购） |
| **付费能力** | 月费 20,000-50,000 RMB（批量） |
| **决策周期** | 2-4 周 |

### 1.3 核心功能（MVP 三件套）

```
功能 1: 商品参数结构化
  · 输入: 商家现有详情页 / SKU数据
  · 处理: 抽取属性-值对，结构化知识图谱
  · 输出: AI可读的结构化商品数据 + 补全建议

功能 2: AI导购收录监测
  · 输入: 商家SKU列表 + 目标平台
  · 处理: 每日模拟AI问询（"推荐一款XX产品"类问题）
  · 输出: 被推荐/未被推荐记录，推荐位排名

功能 3: 优化建议周报
  · 输入: 收录监测数据 + 参数完整度
  · 处理: 对比基线，分析差距，生成建议
  · 输出: 本周推荐变化 + 参数优化建议 + 效果估算
```

### 2.2 功能优先级说明

```
为什么P0只有三个功能?

原因: Phase 1 是服务验证阶段，不是产品开发阶段。
  · 参数结构化 → 解决"AI读不懂我"的核心问题
  · 收录监测 → 提供数据支撑（让商家看到变化）
  · 周报 → 续费依据（持续价值证明）

三个功能组合 = 最小可验证服务单元 (MVS - Minimum Viable Service)
```

| 指标 | Phase 1（8周）目标 | Phase 2（6月）目标 | 验证方法 |

### 3.2 产品指标

| 指标 | 定义 | 目标 | 测量方式 |
|------|------|------|---------|
| 参数完整度提升 | 优化前后结构化程度 | +30ppt（60%→90%） | 自动化评估 |
| AI收录提升率 | 优化后被AI推荐的频次变化 | ≥30% | 监测系统 |
| 客户满意度 | 服务交付满意度 | ≥4.0/5.0 | 月度问卷 |
| 周报打开率 | 客户打开周报的比例 | ≥60% | 链接追踪 |
| 建议采纳率 | 客户执行优化建议的比例 | ≥50% | 执行跟踪 |

### 3.3 验证方法

```
方法 1: A/B 测试（最优）
  · 同一商家，部分SKU优化，部分不优化
  · 对比两组AI推荐收录率
  · 周期: 2-4 周

方法 2: 前后对比（次优）
  · 同一商家，优化前收录基线 vs 优化后
  · 周期: 4-8 周

方法 3: 访谈验证（辅助）
  · 客户主观感受、续费意愿
  · 周期: 随时

验证触发:
  · 每2周一次数据汇报
  · 每4周一次Go/No-Go复盘
```

## 6. Go/No-Go 标准

### 6.1 Phase 1 完成 Go/No-Go 标准（8周末）

#### Go 条件（全部满足才继续）

```
✅ 客户验证:
  · 完成 ≥15 次访谈
  · AI导购重要性认同度 ≥80%
  · 付费意愿 ≥50%（月费≥3000 RMB）
  
✅ 效果验证:
  · ≥2 个试点店的AI推荐收录率提升 ≥30%
  · 参数完整度提升至 ≥85%
  
✅ 商业验证:
  · ≥3 个付费客户
  · MRR ≥1.5 万 RMB
  · 续费意愿 ≥60%
  
✅ 单位经济:
  · LTV/CAC 预计 >3:1
```

#### 继续条件（部分未达标时的决策）

```
如果效果验证未达，但客户验证通过:
  → 调整优化方法，延长试点2-4周
  
如果付费意愿低（<50%）:
  → 调整定价（降至2000/月）或转向效果分成
  
如果收录提升效果不稳定:
  → 聚焦效果最好的类目（通常是保健品）
```

#### 停止条件（触发任一则停止）

```
❌ 访谈数据: AI导购重要性认同度 <50%
❌ 付费意愿: 任何定价下愿付比例 <30%
❌ 效果验证: 所有试点店收录提升 <10%
❌ 商业验证: 8周内无付费客户
```

### 6.2 执行检查清单

```
Week 2 末检查点:
  □ 访谈 ≥10 次完成
  □ 初步判断需求真实性
  □ 确定2-3家试点店

Week 4 末检查点:
  □ 访谈 ≥15 次完成
  □ 收录提升数据初见
  □ 至少1次付费谈判

Week 8 末最终检查点:
  □ 对比Go/No-Go标准
  □ 决策: 进入Phase 2 / 调整 / 停止
```

## 7. 附录

### A. 类目专项规格

#### A1. 保健品类参数结构化要点

```
必须结构化的属性:
  · 功效/适用人群 (主功效 + 次要功效)
  · 成分/配方 (主要成分 + 含量)
  · 规格/用量 (容量 + 建议用法)
  · 认证信息 (保健食品许可证号 + 功效声称)
  · 适用禁忌 (禁忌人群 + 注意事项)
  · 对比维度 (vs 竞品的核心差异)

AI问询模拟问题集（保健品）:
  · "推荐一款适合40岁以上中老年的关节保健品"
  · "帮我找维生素D3含量高的产品，价格100以内"
  · "我最近睡眠不好，有什么保健品推荐？"
  · "哪款鱼油产品EPA+DHA含量最高？"
```

#### A2. 母婴类参数结构化要点

```
必须结构化的属性:
  · 适用月龄 (明确年龄段)
  · 安全认证 (3C/EN71/FDA等)
  · 材质安全 (无BPA/无荧光剂)
  · 功能发展 (开发哪项能力)
  · 使用场景 (户内/户外/旅行)

AI问询模拟问题集（母婴）:
  · "推荐6-12个月婴儿适合的益智玩具"
  · "我家宝宝快断奶了，哪款奶粉过渡最好"
```
