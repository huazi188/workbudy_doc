## MVP 目标和用户

小研发团队工程经理采购，移动端值班人员跟踪其授权开发任务。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 通过既有用户授权接口显示只读任务状态、关键变更摘要和原工具待审链接，支持关闭通知。

**对照流程** 与网页版和团队消息串比较任务确认、响应时间、通知重叠和错误自行批准。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选两个非生产代码库，回放任务完成、超时、人工取消与状态失联，观察移动端确认时间。

**首轮验收门槛** 对30个测试任务，状态显示准确率≥95%，跨项目通知0条，10次审批链接均返回官方授权入口。

## 最小权限与异常处理

移动端展示工作区内容或误触发批准。默认展示任务级摘要，跳回已有认证页面进行操作。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按团队设备或席位订阅，以至少1个小团队支出一月监督层预算验证。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
