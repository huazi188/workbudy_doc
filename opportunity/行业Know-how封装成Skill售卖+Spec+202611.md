## MVP 目标和用户

牧场生产培训主管或乳企采购运营负责人买单，班长和新员工使用。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 用批准的饲喂记录模板、设备日检标准和员工问答制作可审定的运营技能及版本记录。

**对照流程** 对照纸质SOP和班长口授，比较新人找到规范答案的时间及记录漏项。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 围绕交接班和设备点检跑一个班组，首两周收集无解问题和内容管理员更新耗时。

**首轮验收门槛** 40道常规运营题复核正确≥90%，日检字段齐全率≥95%，涉及动物诊疗问题全部人工转接。

## 最小权限与异常处理

旧版标准混入答案或误触诊疗时可能误导，只使用现行非诊疗文档并保留审核责任。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按牧场单站点年费或单技能许可报价，通过一家牧场的预付款验证。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
