## MVP 目标和用户

有月度在线推理账单的中小AI产品负责人采购，技术负责人和采购共同使用。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 按自有许可任务和供应商正式报价生成可比较的吞吐、延迟、配额与成本样表。

**对照流程** 对照仅按标价页人工搜集，用同类通过质量验证任务比较含等待和重试的费用。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 限定一个公开推理任务和同区域用法，把吞吐、一次成功率和超配额风险一起对表。

**首轮验收门槛** 至少3家同口径试测，每家记录100个成功任务，币种、日期、区域和配额条件记录率100%。

## 最小权限与异常处理

宣称单价可能忽略最低消费与供给波动，确认有效书面报价并标注适用条件。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按一次选型报告和采购协调固定费收费，向有当季采购排期团队试收选型费。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
