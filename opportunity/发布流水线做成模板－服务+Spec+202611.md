## MVP 目标和用户

独立创作者与小内容团队购买初始化，主编和运营管理审批与发布。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 以创作者授权素材、文章模板和发布目标生成版本化流程、预览及归档指南。

**对照流程** 与手工复制到多个CMS比较准备时长、版本一致性与双重发布数。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选一个站点与两个内容类型，跑草稿、撤回、占位图片、版面调整和后续归档。

**首轮验收门槛** 连续跑10篇试稿，全部有审批标记和版本回退，发布重复0篇，准备工时下降≥25%。

## 最小权限与异常处理

接口权限过大或意外发布草稿。以预览为默认，人工批准后经授权连接发布。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

免费开放自有工作流的通用代码，按初始化迁移及培训收费，15天内测小团队实际付费。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
