## MVP 目标和用户

传统玩具或音箱厂产品经理采购，质量工程师与试用者验证。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 把已授权语音模组接入一款低风险样机，提供固定话题演示、成本表、网络失效回退及说明。

**对照流程** 对照无语音原机和现成通用模组，测交互成功率和目标硬件增量成本。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 先选一款已有控制接口的音箱，做一个问答和一个设备指令场景，测离线兜底及现有壳体的装配性。

**首轮验收门槛** 拟10台工程样机各跑30轮基本指令，成功率≥95%，断网后全部能恢复基础功能，采购签收成本上限。

## 最小权限与异常处理

语音数据和儿童场景要求由客户确认，样机使用固定内容和成人测试，不保存原始录音。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按样机验证和后续模组采购量报价，以原型阶段预付款和量产意向验证。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
