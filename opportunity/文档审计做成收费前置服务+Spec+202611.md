## MVP 目标和用户

有大量设备手册与SOP的制造厂，质量或设备负责人购买审计，维修人员与文控共审样本。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 交付PDF可读性、版本重复、图表拆解、权限与归档整改报告，输入经批准的抽样目录及设备手册。

**对照流程** 对照全量导入再人工找错，比较上线前暴露的不可解析、版本冲突和查证所需工时。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 第一周在客户批准环境抽样并复核20份，第二周交问题分布、10条带出处的检索题及分批整改报价。

**首轮验收门槛** 拟抽样100份按扫描件、原生PDF和含图表文件分层，失败件识别召回≥95%，高优先级问题100%给出责任字段及整改样例。

## 最小权限与异常处理

内部机密扩散及对旧版手册误用，厂内或受控处理，出版版本与有效日期逐份核对。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

每100份文档一个固定价审计包，可抵后续部署部分费用，先取得一家工厂的独立审计付费单。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
