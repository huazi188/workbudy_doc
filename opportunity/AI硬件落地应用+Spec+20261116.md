## 📋 产品定义 (Product Definition)

### 核心价值主张
为中小型制造企业和本地服务商提供**轻量化AI硬件落地解决方案**：
- **不停产不改线**: 7天上线，无需改造生产线
- **算得清ROI**: 10个月回本，年省60万+人力成本
- **即插即用**: 单工位部署，支持多工位扩展
- **本地运行**: 数据留在客户本地，无隐私泄露

### 用户画像

#### Primary User: 制造企业运营总监
- **年龄**: 35-55岁
- **教育背景**: 中专-本科
- **痛点**: 质检人力成本高（年72万+）、漏检率高（8%）、返工赔付多（月3.2万）
- **需求**: 能替代人工、见效快、成本可控
- **决策权**: 与老板共同决策，需要完整ROI测算表

#### Secondary User: 工厂质检主管/班长
- **角色**: 日常运维、异常处理
- **需求**: 操作简单、有问题快速解决
- **培训需求**: 2小时即可学会

#### Tertiary User: IT/设备主管
- **角色**: 系统集成、远程监控
- **需求**: 接入现有MES/ERP系统
- **技术要求**: REST API、MQTT等标准协议

### 客户细分

| 细分 | 特征 | 规模 | 优先级 |
|-----|------|------|--------|
| **汽配厂** | 两班倒质检，缺陷类型单一，年人力成本50-100万 | 5000家 | P0 |
| **纺织厂** | 断纱监测，女工能看4台机，寻求效率翻倍 | 3000家 | P0 |
| **五金厂** | 表面质检，漏检导致返工赔付高 | 4000家 | P0 |
| **本地服务商** | 暖通/水管/害虫防治，缺前台+调度 | 10万家 | P1 |
| **工地/物流** | 临时场景，需要短租模式 | 1万个 | P1 |

### 成功标准

#### 用户角度
- 质检岗从8人减至1人（人力成本节省75%）
- 漏检率从8%降至≤0.5%（质量提升94%）
- 月返工赔付从3.2万降至≤2000元（损失减少94%）
- 日检测产能从8000件升至15000件（效率提升87%）

#### 商业角度
- 单工位投入5-8万元，10个月回本
- 首年收入150-220万元，毛利率55-65%
- 转介绍率≥40%，客户续约率≥70%
- 累计客户≥20家

## 🔧 功能规格 (Feature Specification)

### Phase 1 (MVP): 核心功能 (P0)

#### F1.1 工业相机 + 边缘计算盒

**硬件配置**:
- 工业相机: 200万像素彩色相机（支持常见光线条件）
- 边缘计算盒: Jetson Orin或同等ARM处理器（本地离线推理）
- 安装支架: 可调节角度和距离，适配不同生产线
- 电源: 220V转12V/24V电源管理

**规格要求**:
- 检测速度: ≤200ms/帧（单张图片检测时间）
- 准确率: ≥95%（对比人工质检）
- 可靠性: ≥99.5%（年故障率≤44小时）
- 工作温度: 0-50°C
- 防护等级: IP65（防尘防水）

**成本**: 2-3万元/套

#### F1.2 定制模型训练

**功能**:
- 自动采集客户样本图片（1000-2000张）
- 标注缺陷类型（划痕、色差、变形、毛刺等）
- 使用迁移学习快速训练专属模型（3-5天）
- 模型精度测试和调优

**输入**:
- 样本图片（不同光线、角度、缺陷类型）
- 缺陷定义（什么算缺陷，什么不算）

**输出**:
- 训练完成的模型文件（部署到边缘盒）
- 模型性能报告（精度、召回率、F1分数）
- 调试建议（光线优化、相机位置等）

**规格要求**:
- 检测精度: ≥95%
- 召回率: ≥90%（不漏检关键缺陷）
- 误检率: ≤5%（误检不影响生产）
- 适应性: 支持5-10种缺陷类型

#### F1.3 快速部署流程

**部署周期**: 7天

| 环节 | 耗时 | 任务 |
|-----|------|------|
| **Day 1-2** | 现场勘查 | 确定相机位置、光线条件、接电方案 |
| **Day 3-4** | 安装调试 | 安装相机+边缘盒，采集样本 |
| **Day 5-6** | 模型训练 | 标注样本，训练模型 |
| **Day 7** | 上线运行 | 模型部署，员工培训（2小时） |

**质量保证**:
- 现场勘查报告（照片+建议）
- 安装验收单（署名确认）
- 模型测试报告（精度数据）
- 上线交接清单

#### F1.4 ROI 测算工具

**输入**:
- 现有质检岗人数（如：8人）
- 月人力成本（如：6万元）
- 当前漏检率（如：8%）
- 月返工赔付（如：3.2万元）
- 日检测件数（如：8000件）

**自动计算**:
- **年人力成本节省**: 6万/月 × 7人 × 12月 = 504万 → 实际预期 60万
- **年返工赔付减少**: 3.2万/月 × 12月 × 94% = 36万
- **产能提升收益**: (15000-8000件)/日 × 单件毛利 × 250工作日
- **一次性投入**: 6.5万元（硬件+部署+培训）
- **回本周期**: 6.5万 / (96万/12) = 0.8个月 = **10个月**

**输出**:
- 可视化ROI表格（月度、季度、年度对比）
- PDF格式报告（可打印给老板看）
- 保守方案、中间方案、乐观方案（三种预测）

#### F1.5 远程监控平台（Web版）

**功能**:
- 实时检测结果展示（检测通过/不通过的图片）
- 历史数据查询（按日期、班次、产品类型）
- 精度/漏检率/产能数据看板
- 告警通知（连续不通过、设备离线等）
- 管理员账户管理

**界面**:
```
顶部导航: 实时监测 | 数据分析 | 告警中心 | 系统设置

实时监测:
  ├─ 摄像头实时画面（检测框标注）
  ├─ 当前状态（运行中/异常停止）
  ├─ 今日统计（检测件数、通过率、异常件数）
  └─ 最近10张异常图片

数据分析:
  ├─ 日/周/月精度趋势图
  ├─ 缺陷类型分布（划痕/色差/变形/...）
  ├─ 产能提升曲线
  └─ 下载报告（PDF/Excel）

告警中心:
  ├─ 连续3张不通过告警
  ├─ 设备离线告警
  ├─ 模型精度下降告警
  └─ 告警历史和处理记录
```

**访问方式**: Web界面（https://platform.xxx.com），支持手机和电脑

**用户角色**:
- 管理员: 可看所有项目、管理用户、导出数据
- 项目主管: 只看本项目、查看数据、下载报告
- 操作员: 只看实时画面、记录异常

### Phase 2 (Scale): 增强功能 (P1)

#### F2.1 多工位联动

**功能**: 一套系统管理5-10个质检工位

**设计**:
- 支持多个摄像头同时运行
- 统一的远程监控平台
- 按工位、班次、产品类型的分组统计

**规格**:
- 支持≤10个摄像头同时运行
- 单个摄像头性能不受其他影响
- 平台服务器配置: 2核4GB内存起

#### F2.2 租赁模式支持

**功能**: 按月租赁而不是一次性购买

**计费模式**:
- 月租金: 3000-5000元/工位（含硬件折旧+维保+软件+数据存储）
- 超额费用: 若月度检测件数>预定值，按0.1-0.2元/件额外收费
- 合同期限: 12-36个月（满期可转购或续租）

**服务内容**:
- 硬件维护（坏了免费换）
- 软件升级（新功能免费享用）
- 远程支持（响应时间≤2小时）
- 月度数据报告（自动发送）

#### F2.3 缺陷分析报告

**功能**: 自动生成"高频缺陷类型"分析

**内容**:
- 本月高频缺陷TOP 5（及其发生班次、班长、原因初步猜测）
- 缺陷趋势（周环比、月环比）
- 改进建议（如：增加光线、调整相机角度等）
- 与行业基准对比

**周期**: 自动生成每周一和每月底

#### F2.4 MES/ERP 系统集成

**功能**: 与客户现有系统打通

**对接方式**:
- REST API（标准HTTP接口）
- 数据格式: JSON
- 支持的集成: 产品追溯、质检结果推送、不良品标记等

**示例API**:
```
POST /api/v1/inspection-result
{
  "product_id": "xxx",
  "batch_id": "yyy",
  "result": "pass/fail",
  "timestamp": "2026-11-16 14:30:25",
  "defect_types": ["划痕", "色差"],
  "confidence": 0.98
}
```

### Phase 3 (Optimize): 优化功能 (P2)

#### F3.1 移动APP监控

**功能**: iOS/Android APP实时查看质检结果

**核心**: 推送告警、查看实时画面、下载报告

#### F3.2 AI 缺陷诊断

**功能**: 自动分析缺陷原因（光线问题/产品工艺问题/相机故障等）

#### F3.3 跨工位学习

**功能**: 多个客户的数据共享学习，不断优化模型准确率

**定价**:
- 单工位套餐: 6.5万元/套（一次性）
- 两工位套餐: 11万元（优惠）
- 多工位套餐（≥3): 5.5万元/工位（量价优惠）

**包含内容**:
- 工业相机 + 边缘计算盒（硬件）
- 定制模型训练（软件）
- 7天快速部署（服务）
- 1年免费维保（包括硬件故障更换）
- 12个月远程监控平台使用权

**超期费用**:
- 1年后继续使用平台: 1000元/年

```

  - 硬件: 2.5万

毛利: 2.5万 (38%)
毛利率: 38%

净利润（扣除运营费）: 1.5万 (23%)
```

## 🎯 Go/No-Go 标准

### Phase 1 结束时（Week 8）

**✅ 继续到 Phase 2 的条件** (同时满足):
- ≥3家客户签约
- 第一个试点7天内上线
- 检测精度≥95%
- 漏检率≤0.5%
- ≥80%客户认可ROI
- ≥1家客户转介绍

**❌ 停止的条件** (任一满足):
- <2家客户签约
- 部署周期>10天
- 检测精度<90%
- 漏检率>2%
- <50%客户认可ROI

### Phase 2 结束时（Week 20）

**✅ 继续到 Phase 3 的条件**:
- ≥10家累计客户
- 单项目毛利率≥50%
- 转介绍率≥30%
- 年收入≥80万

**❌ 停止的条件**:
- <5家累计客户
- 单项目毛利率<40%
- 无转介绍
- 年收入<50万
