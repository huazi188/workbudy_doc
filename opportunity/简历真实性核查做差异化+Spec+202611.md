## MVP 目标和用户

需要改善简历可信度的转岗人群购买，人力资源或职业指导人员可购买团体核对。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 根据用户自身提供的记录将简历逐条分为有依据、缺材料、表述需确认，交付修订清单。

**对照流程** 与职业老师审改和通用改写工具比较新造信息数、条目证据覆盖与耗时。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选择一类管理岗位，用虚构示例校准后让20人自行核验3到5条含数字的过往绩效。

**首轮验收门槛** 20份匿名样本由2名评审复核，证据不足任务标识率≥95%，自行增加成绩、证明或岗位经历0项。

## 最小权限与异常处理

求职者资料含身份和现雇主信息。仅使用出示资料，允许删除，风险条目标给本人确认。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按简历或岗位适配包收费，测首次免费核对后对于人工复核或做第二份的付款。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
