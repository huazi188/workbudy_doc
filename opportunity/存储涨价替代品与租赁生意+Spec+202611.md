## MVP 目标和用户

短期拍摄的创作者和小工作室使用，租赁运营商负责人投入库存。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 交付租买比价页、押金和保险说明、设备可用日历及领取归还清单，输入签约价格与自有库存。

**对照流程** 比较既有租赁列表页和整机购买，记录比较计算启动到订单转化、损耗金额与周转天数。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 先用现有一台设备试运转，给买前和有刚需期限的两种用户展示比价页与常规页对照。

**首轮验收门槛** 拟两周取得至少5个完成归还的订单，单设备档期利用率≥30%，在押金和折旧后贡献为正。

## 最小权限与异常处理

涨价或缺货来源不可靠且多日损伤难追，价格记版本和日期，交易前后拍摄并由双方对账。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按日与周末套餐报价，通过实付租金、延租和归还损耗衡量需求。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
