## 2. Phase 1: 验证期（Week 1-8）

### 2.1 Week 1-2: 深度调研 + MVP内容制作

#### 目标
- 理解客户痛点
- 产出对比选购指南
- 验证选型困惑真实存在

#### 详细任务（Day-by-Day）

**Day 1-2: 准备阶段**
- [ ] 制定访谈脚本（7个核心问题）
  - Q1: 您是什么时候、因为什么决定购买Token包的？
  - Q2: 购买前有对比过不同模型/套餐吗？怎么比的？
  - Q3: 最后选择XX模型/套餐的原因是什么？
  - Q4: 购买后实际使用中有遇到"选错了"的情况吗？
  - Q5: 如果有人帮您做选型分析，您愿意为此付费吗？预期价格？
  - Q6: Token用完后会续费还是换其他模型？为什么？
  - Q7: 您会推荐朋友来咨询选型服务吗？
- [ ] 设计访谈记录表（Excel模板）
- [ ] 招募20个受访者
  - 小红书发帖：【招募】双11购买Token的朋友，聊聊选型困惑（送50元红包）
  - 即刻发帖：同上
  - 电商卖家群：同上（3个群）
- [ ] 采购访谈礼品（微信红包50元×20人=1000元）

**Day 3-7: 执行访谈**
- [ ] 每天完成3-4个访谈（每人30分钟，远程/线下均可）
- [ ] 每日整理访谈笔记，提取关键洞察
  - 选型困惑点（高频词汇、痛点描述）
  - 付费意愿（明确/模糊/拒绝）
  - 预期价格区间（<100元 / 100-300元 / >300元）
- [ ] 汇总洞察文档（Notion/飞书文档）

**Day 8-14: 内容制作（并行进行）**
- [ ] 研究8大模型
  - GPT-4 Turbo / Claude 3.5 Sonnet / 文心一言4.0 / 千问Max / DeepSeek V2 / Kimi / MiniMax / 智谱GLM-4
  - 收集数据：响应速度（官方Benchmark+实测）、准确率（第三方评测）、价格（官网）
- [ ] 制作性能对比表（Figma/Excel）
  - 表头：模型名称 | 响应速度(ms) | 准确率(%) | 价格(元/1M tokens) | 适用场景
  - 填充数据并美化
- [ ] 设计场景适配矩阵（Figma）
  - 横轴：写作/客服/编程/图片生成
  - 纵轴：8大模型
  - 填充：⭐⭐⭐（强推荐）⭐⭐（推荐）⭐（可用）—（不适用）
- [ ] 开发Token用量估算器（简单HTML+JS）
  - 输入：场景类型（下拉菜单）+ 每日使用频率（滑块）
  - 输出：推荐套餐 + 预期月消耗（Token数）+ 月成本预估（元）
  - 嵌入文章中（CodePen/JSFiddle链接）
- [ ] 撰写对比指南文章（3个版本）
  - 知乎长文（3000字）：完整版，包含对比表+矩阵+估算器+案例
  - 小红书图文（9图）：精简版，每图1个主题（封面+对比表+场景矩阵+3个案例+结尾引导）
  - 即刻帖子（800字）：核心版，只有对比表+Top 3推荐+估算器链接

#### 成功标准
- 访谈完成率 ≥ 90%（18/20人）
- ≥70%受访者表达选型困惑（核心假设验证）
- 对比指南制作完成并自查质量（无明显错误）

#### 资源投入
- 人力：1人全职（14天）
- 成本：访谈礼品1000元
- 工具：Figma（免费版）+ Notion（免费版）+ CodePen（免费）

### 2.4 Week 7-8: 复购验证 + SaaS化探索

#### 目标
- 验证复购率 ≥ 50%
- 探索自动化可能性（为Phase 2做准备）

#### 详细任务

**Day 45-50: 追踪首批客户**
- [ ] 主动触达Week 5-6的20个付费客户
  - 触达方式：微信消息（非群发，逐一发）
  - 触达内容：
    - 模型更新提醒："XX模型刚降价了，您现在用的套餐可以省XX元"
    - 场景优化建议："根据您的用途，新出的XX模型可能更适合您"
    - 新场景咨询："您最近有新的AI使用场景吗？可以再帮您优化"
- [ ] 测量复购率
  - 统计：20人中有多少人产生第二次咨询
  - 目标：≥10人（50%）
- [ ] 收集复购原因
  - 访谈：为什么又来咨询？（模型变化/场景变化/不满意之前的推荐）
  - 分析：哪些因素促成复购？

**Day 51-56: 探索自动化方案**
- [ ] 设计选型问卷（5分钟填完）
  - 问题1：您主要用AI做什么？（单选：写作/客服/编程/图片生成/其他）
  - 问题2：每天大概用几次？（单选：1-10次 / 10-50次 / 50次以上）
  - 问题3：月预算是多少？（单选：<100元 / 100-500元 / 500-1000元 / >1000元）
  - 问题4：最看重什么？（多选：价格/速度/准确率/功能全面）
  - 问题5：用过哪些模型？满意吗？（开放题）
- [ ] 测试自动生成报告（问卷→决策树→报告）
  - 建立决策树（Python脚本）
    - 规则：IF 用途=写作 AND 预算<500元 THEN 推荐DeepSeek/千问
    - 规则：IF 用途=编程 AND 看重速度 THEN 推荐Claude/GPT-4
    - ...（覆盖20+场景组合）
  - 自动填充报告模板（Python + Word模板）
  - 生成PDF（Python PDF库）
- [ ] 评估准确率
  - 对比：自动报告 vs 人工报告的推荐差异
  - 测试：找5个真实客户,同时给出自动报告和人工报告,看他们选哪个
  - 目标：自动报告准确率 ≥ 80%

**Day 57-58: 计算单位经济**
- [ ] 汇总Phase 1数据
  - 总营销支出：访谈礼品1000元 + 广告500元 + 优惠券1000元（实际支出）= 2500元
  - 付费客户数：30人（Week 5-6的20人 + Week 7-8的10人复购）
  - CAC（获客成本）= 2500 / 30 = 83元/人
  - 客单价：250元（基础档60% × 200元 + 进阶档40% × 500元）
  - 复购次数：1.5次（20人首次 + 10人二次 = 30次 / 20人）
  - LTV（客户终身价值）= 250 × 1.5 = 375元
  - **LTV/CAC = 375 / 83 = 4.5:1** ✅ 通过验证（>3:1）
- [ ] 决策：Phase 1 Go/No-Go
  - 检查所有Go标准：
    - ✅ 付费意愿：48%愿意付费（>40%）
    - ✅ 客单价：250元（>200元）
    - ✅ 复购率：50%（=50%）
    - ✅ LTV/CAC：4.5:1（>3:1）
    - ✅ 自动化可行性：80%场景可决策树解决（=80%）
  - **决策：GO** ✅ 进入Phase 2

  - 岗位：产品经理/开发工程师（兼职或全职）
