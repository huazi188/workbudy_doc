## 1. Phase 规划

### Phase 1: 验证期（Week 1-8）

**目标**: 验证需求真实性、服务可行性、商业模型

```
时间: 2026-11-15 → 2027-01-10
核心问题: 
  "高比较成本类目商家真的愿意为AI导购优化付费吗？
   我们能稳定提升AI推荐收录率吗？"

成功标准:
  · 15+ 访谈完成，认同度 ≥80%
  · 2-3 试点店收录提升 ≥30%
  · 3-5 付费客户，MRR ≥1.5万
  · 续费意愿 ≥60%

失败退出条件:
  · 收录提升 <10%（产品不work）
  · 付费意愿 <30%（需求不够强）
```

### Phase 2: 产品市场适配（Week 9-24）

**目标**: 建立可重复销售流程，半自动化服务，扩展到50+客户

```
时间: 2027-01-11 → 2027-05-10
核心问题:
  "我们能以稳定的CAC获取客户吗？
   服务能否标准化服务更多客户？"

成功标准:
  · 50+ 付费客户
  · MRR ≥25 万 RMB
  · CAC ≤5000 RMB
  · LTV ≥2 万 RMB
  · 续费率 ≥65%

关键里程碑:
  · Week 12: 服务SOP完成，第一套标准化包
  · Week 16: 半自动化工具上线
  · Week 20: 10+ 保健品客户案例库
  · Week 24: ARR ≥300 万，考虑融资
```

### Phase 3: 市场验证（Week 25-36）

**目标**: 验证规模化路径，扩展到200+客户，SaaS产品化

```
时间: 2027-05-11 → 2027-08-10
核心问题:
  "商家自助工具可行吗？
   我们能以更低CAC规模化获客吗？"

成功标准:
  · 200+ 付费客户
  · MRR ≥100 万 RMB
  · 推出 SaaS Beta 版
  · CAC ≤3000 RMB
  · LTV/CAC ≥5:1

关键里程碑:
  · Week 28: SaaS Beta 内测（20家）
  · Week 32: 完成 500-1000 万种子融资
  · Week 36: 月增长 ≥15%
```

### Phase 4: 规模化（Week 37+）

**目标**: 进入规模化增长，建立市场领导地位

```
时间: 2027-08-11 →
核心任务:
  · SaaS 产品全面上线
  · 合作伙伴渠道（代运营公司）
  · 多类目扩展（从保健品扩展到全类目）
  · 技术壁垒建设（专有AI导购数据库）

成功标准:
  · 2000+ 付费客户
  · ARR ≥5000 万 RMB
  · 市场占有率 SAM 的 5%+
```

## 5. 风险缓解

### 5.1 识别的风险

| 风险ID | 风险描述 | 可能性 | 影响 | 缓解措施 |
|--------|---------|--------|------|---------|
| R1 | 平台AI导购逻辑调整，优化方法失效 | 中 | 高 | 多平台分散 + 快速迭代适配 |
| R2 | 平台推出免费商家工具挤压空间 | 中 | 高 | 聚焦平台不服务的深度定制 |
| R3 | 收录提升效果不稳定（类目差异） | 中 | 中 | 聚焦效果最好的类目（保健品） |
| R4 | 商家付费意愿低于预期 | 中 | 高 | 效果分成定价选项 |
| R5 | 技术人才难招 | 低 | 中 | Phase 1 外包，Phase 2 招聘 |
| R6 | 竞争者快速跟进 | 中 | 中 | 客户锁定 + 数据壁垒 |
| R7 | 数据合规风险（爬虫） | 中 | 高 | 仅用公开接口 + 法务前置 |

### 5.2 风险缓解详细方案

#### R1: 平台逻辑调整

```
预防:
  · 订阅平台AI导购政策变动通知
  · 建立商家社群获取一手反馈
  · 技术架构设计为可插拔式（平台适配层）

应对:
  · 平台调整后48小时内出应急指南
  · 向客户同步说明，调整优化方案
  · 以"持续更新跟进平台最新算法"作为核心卖点
```

#### R4: 付费意愿偏低

```
预防:
  · Phase 1 试点先做免费，积累效果数据
  · 用实测数据（+30%收录，+X%成交）建立信任
  · 提供"无效退款"保证

应对:
  · 切换至效果分成定价（零门槛）
  · 降低起步价至2000/月（增加准入门槛后再提价）
  · 转向代运营公司B2B采购（降低单客CAC）
```

#### R7: 数据合规

```
预防:
  · 法律顾问前置审查（2000-5000 RMB一次）
  · 建立合规白名单（平台允许的接口清单）
  · 仅用平台公开商品展示数据，不触碰用户行为数据

应对:
  · 收到平台警告立即停止相关行为
  · 转向使用官方API（成本更高但合规）
```

### 5.3 监测指标

| 风险 | 告警指标 | 告警阈值 | 响应时间 |
|------|---------|---------|---------|
| R1 | 收录提升效果周均下降 | 连续2周下降>10% | 48小时内响应 |
| R3 | 客户续费率下降 | 月续费率<50% | 2周内复盘 |
| R4 | 付费转化率 | Phase 1 末 <30% | 立即调整定价 |
| R7 | 平台封号或警告 | 任何封号事件 | 24小时内响应 |

## 6. 决策点和检查清单

### 6.1 Phase 1 末 Go/No-Go 检查清单（Week 8）

```
客户验证:
  □ 访谈数 ≥15
  □ AI导购重要性认同度 ≥80%
  □ 付费意愿 ≥50%（月费≥3000）
  
效果验证:
  □ 试点店AI推荐收录提升 ≥30%
  □ 至少2家试点店完成验证
  
商业验证:
  □ 付费客户 ≥3 家
  □ MRR ≥1.5 万
  □ 续费意愿 ≥60%
  
团队验证:
  □ 技术员到位
  □ 服务SOP完成
  □ 下一步销售渠道明确
  
决策:
  · 全部通过 → 进入 Phase 2
  · 部分通过 → 识别原因，2-4周微调后复盘
  · 效果验证失败 → 换类目重试（母婴/3C）
  · 付费验证失败且切换定价无效 → 停止
```

### 6.2 重要决策矩阵

| 场景 | 触发条件 | 决策 | 执行人 |
|------|---------|------|--------|
| Phase 1 -> Phase 2 | 全部Go指标达成 | 进入Phase 2 | 创始人 |
| 类目调整 | 保健品效果不达，母婴/3C表现好 | 切换主类目 | 创始人 |
| 定价调整 | 月费模式付费率<30% | 切换效果分成 | 创始人 |
| 融资决策 | ARR ≥300万，月增≥15% | 启动种子轮融资 | 创始人 |
| SaaS化决策 | 50+客户，服务标准化90% | 启动产品化 | 创始人+技术 |
| 停止决策 | 8周内无付费客户且定价调整无效 | 转向其他机会 | 创始人 |
