## 1. 核心规格

### 1.1 产品定义

**产品名称**: 岗位智能体交付服务（Workforce Agent Delivery Service）

**一句话定义**: 为中型企业提供「岗位遍历 + 技能包 + 智能体上线」一站式交付，以节省人力成本分成计费。

**解决的核心问题**:
- 企业知道要用 AI 但不知从哪个岗位切入，重复试错 6-12 个月
- 神州控股验证路径不可自研，腰部品牌/仓配公司需要外部交付能力
- 现有 AI 工具商只卖软件，不帮企业做组织变革

**产品本质**: 这不是一个软件产品，是以 AI 工具为核心的**专业服务产品**
- 交付物是：岗位分析报告 + 技能包 + 智能体配置 + 培训
- 收费是：服务费（固定）+ 效果分成（可选）
- 护城河是：积累的行业岗位知识库 + 交付方法论

### 1.2 目标用户画像

#### 用户群 A：中型品牌商（首选）

```
特征:
├─ 年销售额: 1-10亿人民币
├─ 员工规模: 50-500人
├─ 电商团队: 10-50人（内容/客服/运营）
├─ AI 现状: 有零散工具，无系统方法
└─ 决策人: 运营总监 / COO / 老板本人

痛点:
├─ 双11这类大促人力紧张，AI 一直没跑通
├─ 客服工单量大，AI 客服上了但老出幻觉
└─ 内容上新慢，美工 AI 化但质量不稳定

付费意愿: 15-50万/次服务，愿意试效果分成
```

#### 用户群 B：中型仓配/代运营公司（高价值）

```
特征:
├─ 年营收: 5000万-5亿
├─ 员工规模: 100-2000人（大量一线操作岗）
├─ AI 现状: 仓内有些自动化硬件，软件层空白
└─ 决策人: 总经理 / 信息化负责人

痛点:
├─ 人效提升是核心KPI，每年都在想怎么降人力成本
├─ 拣货/质检/客服三个岗位重复劳动比例最高
└─ 以前请咨询公司做流程改造没效果

付费意愿: 20-80万/次，对效果分成接受度高
```

#### 用户群 C：跨境独立站商家（快速验证辅助线）

```
通过客服代理产品切入，客单价低但决策快
├─ 月费 1500-3000元 + 按工单计费
└─ 验证路径: 2 周出数据
```

### 1.3 核心功能描述

#### 功能模块 1：岗位遍历系统（核心）

```
目标: 在 4-8 周内完成企业全岗位 AI 化机会扫描

输入:
└─ 企业组织架构 + 岗位说明书 + 一周工作日志样本

过程:
├─ 岗位问卷（每岗位 20 个标准问题）
├─ 操作录像分析（1-2 人/岗位，录制 2-3 小时操作）
├─ 技能包可行性评分（AI 替代度 0-100%）
└─ 优先级排序（以节省人时 × 技术可行性 × 实施风险排序）

输出:
├─ 岗位 AI 化机会图（热力图形式）
├─ Top 10 岗位的技能包草稿
└─ ROI 预估报告（节省人时 + 节省人力成本测算）
```

#### 功能模块 2：技能包制作（核心）

```
目标: 把老师傅经验写成 AI 可执行的 Prompt + 工具调用流程

输入: 岗位遍历报告 + 老员工经验访谈录音

过程:
├─ 经验提炼（把隐性知识写成显性流程）
├─ Prompt 工程（针对主流大模型优化，可切换）
├─ 工具调用配置（接入 ERP/WMS/CRM 等现有系统）
└─ 验收测试（老员工对比 AI 输出的准确率评估）

输出:
├─ 技能包文档（每个技能包 5-15 页）
├─ 配置好的智能体（部署在钉钉/企微/独立客户端）
└─ 使用手册 + 培训 PPT
```

#### 功能模块 3：效果监测仪表板（增值）

```
目标: 量化节省人时，支持效果分成计算

监测指标:
├─ 每日/周/月：AI 处理工单数 vs 人工处理工单数
├─ 准确率趋势（AI 输出被人工修改的比例）
├─ 人力投入对比（AI 上线前后人均工时）
└─ 节省人力成本计算（基于企业人力单价）

报告形式: 月度效果报告（PDF + 数据看板）
```

## 2. 功能规格

### 2.1 MVP 功能清单（P0 — 必须有）

| 功能 | 描述 | 交付形式 | 时间成本 |
|-----|------|--------|--------|
| 岗位遍历问卷 | 20题标准化问卷，覆盖重复度/技术可行性/风险 | Google Form / 腾讯问卷 | 1周 |
| 岗位操作录制分析 | 录屏工具 + 人工分析 → 操作步骤文档 | Word文档 | 2周/企业 |
| 技能包模板 | 10类核心岗位技能包模板（客服/仓配/内容/运营）| Notion模板库 | 2周制作 |
| 智能体配置部署 | 对接钉钉/企微机器人接口，上线技能包 | 配置文档+上线 | 1周/企业 |
| 效果基线采集 | 上线前4周人力投入记录（作为对比基准） | Excel表格 | 持续 |

### 2.2 P1 功能（Phase 2 添加）

| 功能 | 描述 | 优先触发条件 |
|-----|------|-----------|
| 技能包自动生成 | 基于录像自动提炼流程（AI + 人工审核） | 客户数量 > 10家 |
| 效果仪表板 SaaS | 月度效果报告自动生成 | 客户 > 20家 |
| 多企业技能包复用库 | 同类岗位跨企业知识迁移 | 完成5家同类企业 |

### 2.3 P2 功能（规模化后）

- 技能包市场（企业间交易）
- 实时人效监测 API
- 垂直行业技能包预训练版本

### 2.4 功能优先级排序逻辑

**排序原则**: 节省客户时间（P0） > 效果量化能力（P1） > 规模化效率（P2）

原因：Phase 1 核心是证明「能省时间」，这是签单和分成的基础。效果量化是第二步，规模化是第三步。

## 4. 定价和商业模式

### 4.1 订阅/服务方案

#### 方案 A：基础服务包（岗位遍历 + 技能包）

```
价格: 15-30万/家（依规模定价）
  ├─ 50人以下企业: 15万
  ├─ 50-200人企业: 20万
  ├─ 200-500人企业: 30万
  └─ 500人以上企业: 定制

包含:
  ├─ 全岗位遍历（50-150个岗位）
  ├─ Top 20 岗位技能包制作
  ├─ 2 个智能体上线（钉钉或企微）
  ├─ 员工培训（1天）
  └─ 3个月效果跟踪报告
```

#### 方案 B：效果分成包（Premium）

```
前置费用: 5-10万（调研+分析成本回收）
分成比例: 实际节省人力成本的 15-20%
分成期限: 12-24 个月
计算公式: 节省人时 × 员工时薪 × 分成比例

适用场景: 客户对固定费用敏感但对效果自信
风险: 计量纠纷（通过第三方数据确认缓解）
```

#### 方案 C：客服代理月服务（快速入口）

```
基础月费: 1500-3000元/店铺
工单计费: 3-5元/自动处理工单
附加: 知识库配置费（首次 3000-5000元）

目标客户: 跨境独立站、天猫/京东店铺
验证路径: 2周交付第一版，1个月看数据
```

### 4.2 收费模式选择逻辑

```
客户决策速度 ×  客户规模 → 推荐方案

快决策 + 小规模（<50人）: 客服代理月服务（方案C）
中决策 + 中规模（50-500人）: 基础服务包（方案A）
慢决策 + 大规模（500人+）: 效果分成（方案B）
```

## 5. 技术架构

### 5.1 系统组件

```
服务层（人工为主，工具辅助）:
├─ 岗位遍历工具套件: 问卷系统 + 录像分析工具
├─ 技能包编辑器: 结构化 Prompt 模板 + 版本管理
├─ 智能体配置平台: 对接主流企业IM（钉钉/企微）
└─ 效果监测仪表板: 数据看板（月度报告）

AI 层:
├─ 大模型接口: 阿里千问/百度文心/月之暗面（按客户需求选型）
├─ 客服代理引擎: RAG + 工具调用（查单/退款/物流）
└─ 质检模型: 图片审美评分 + 视频合规检测

数据层:
├─ 技能包知识库: 结构化文档存储
├─ 效果数据仓库: 人时/工单量历史数据
└─ 客户档案系统: CRM（早期用飞书/Notion）
```

### 5.2 技术栈选型

| 组件 | 选型 | 理由 |
|-----|------|------|
| 大模型 API | 千问 Turbo / 文心 Speed | 国内合规，API 成本低 |
| 智能体框架 | 阿里百炼 / Coze | 已有企业接口，省开发 |
| 客服 AI | Dify（私有部署）| 支持 RAG + 工具调用 |
| 数据看板 | 飞书多维表格 | 无需开发，企业客户熟悉 |
| 知识库管理 | Notion（早期）| 低成本，易协作 |

### 5.3 成本预算（Year 1）

| 成本项 | 月度 | 年度 | 说明 |
|-------|------|------|------|
| 大模型 API | 1-3万 | 15-30万 | 随客户量增长 |
| 云服务器 | 0.5万 | 5万 | 阿里云基础配置 |
| 工具订阅 | 0.3万 | 3万 | Notion/飞书/Dify |
| 人力成本 | 15-20万 | 180-240万 | 10-15人团队 |
| 市场营销 | 5万 | 50万 | 内容营销为主 |
| **总成本** | **22-28万** | **250-330万** | — |

## 6. Go/No-Go 标准

### 6.1 Phase 1 通过条件（8周内，全部满足）

```
✅ 商业验证:
□ 完成 15+ 企业负责人访谈
□ ≥ 50% 受访者有明确签单意向（≥10万合同）
□ 至少 1 家试点合同签署（哪怕 1 万免费/低价试点）

✅ 技术验证:
□ 完成 1 家企业 50+ 岗位遍历，交付时间 ≤ 4个月
□ 技能包被老员工评估准确率 ≥ 80%
□ 实测人效提升 ≥ 20%（有对比数据，非预估）

✅ 产品验证:
□ 技能包模板完成 10 个核心岗位类型
□ 客服代理在至少 3 家店铺跑通（自动处理率 ≥ 65%）
```

### 6.2 继续条件（Phase 2 进入）

```
商业:
□ 年合同签约额 ≥ 500万（来自 10+ 家企业）
□ 客户 NPS ≥ 40

技术:
□ 技能包复用率（第 2 家同类企业交付时间 ≤ 首次 50%）
□ 效果仪表板自动生成月报（无需人工整理）
```

### 6.3 停止条件

```
以下任一条件出现 → 暂停并重新评估:
□ 15 个访谈后，付费意愿低于 20%（市场教育成本太高）
□ 技能包准确率 < 60%（技术路线需调整）
□ 人效提升 < 10%（价值主张不成立）
□ 客户决策周期 > 9个月（B 端销售不可持续）
```
