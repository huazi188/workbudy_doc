## MVP 目标和用户

青训教练与家长使用，操作者可为球队或体育内容创作者。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 用授权视频、公开统计与教练标注制作阵型、转换或逼抢教学片段和练习说明。

**对照流程** 与比分复述及泛化集锦对照，检查教练是否能复用具体镜头和训练要点。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选攻防转换一项，匿名绘制两个时间段的位置示意，由两位教练独立复核。

**首轮验收门槛** 分析3种比赛局面，每种至少标记3个合法引用或自制图示，邀请5名教练中至少3名认可一项可用练习。

## 最小权限与异常处理

未成年球员肖像及转播权风险。场景示意匿名，使用许可素材，避免个人负面归责。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

免费发布一节示意课，按培训或教育授权付费，测试教练或机构的复购。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
