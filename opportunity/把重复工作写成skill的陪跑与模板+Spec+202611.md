## MVP 目标和用户

小型营销服务商负责人及交付执行员。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 一项常用流程的可复用模板、输入输出样例与维护手册。

**对照流程** 比现有共享文档和口头交接测新人上手时间。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选客户周报或素材入库这种可确认重复三次以上的工作。

**首轮验收门槛** 3名未参与制作的同事中≥2名独立通过，耗时缩短≥30%。

## 最小权限与异常处理

模板固化错误做法，由业务负责人逐周复盘更新。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按工作流程包加复盘工时收费，向现有客户出可选报价。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 先验证需求，再决定试点**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
