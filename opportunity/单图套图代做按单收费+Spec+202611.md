## MVP 目标和用户

缺美工的亚马逊小卖家采购，店铺运营验收卖点和规格图。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 以商品原图、尺寸参数和经确认卖点生成九张套图，提供输出尺寸与源文件。

**对照流程** 对照旧外包或商家自行作图，比较同等通过审核的套图交付时间及返修次数。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 只选一个标准商品类目、五个明确授权SKU，报价前准备一张不同卖点的风格样图。

**首轮验收门槛** 首批5个SKU每套9张，两轮内获批比例≥80%，规格数字差错与未证实宣称0个。

## 最小权限与异常处理

AI凭空增加功能、配件或色差。建立来源字段映射和原图对照，每张走清单复核。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按整套收分档费用，可测试源资料齐全的低价档，记录每单实际返修成本与复购。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
