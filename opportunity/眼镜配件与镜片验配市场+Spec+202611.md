## MVP 目标和用户

镜片门店及电商配件卖家是渠道，特定型号AI眼镜的近视用户付费。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 以实物框形和厂商说明做镜片套件适配清单、预约与安装售后说明。

**对照流程** 对比用户自带验配和通用夹片，记录有效安装、佩戴不适及退换货。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选一个已拿到实物的眼镜和获准门店，试两种有明确适用范围的镜片方案，优先测装配稳定度和返工。

**首轮验收门槛** 拟两个实测型号，每型至少10次佩戴记录，装配合格≥95%，两周至少5笔授权门店实付订单。

## 最小权限与异常处理

厂商规格与验配要求可能变化，留真机型号照片并由专业验配人员确认供货及佩戴反馈。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按镜片套件和门店服务费分开收款，小批预售只在验证兼容后开放。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
