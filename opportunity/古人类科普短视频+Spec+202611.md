## MVP 目标和用户

科普内容读者使用，博物馆教育部门或平台专栏可购买授权。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 以论文、博物馆图像授权和研究者公开解释制作一条带不确定性说明的化石短片。

**对照流程** 与只述热搜结论的科普短片比较完播、事实更正率及观众能否解释证据。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 制作同一研究的60秒证据版和3分钟背景版，请学术审阅，比较观众留存及提问。

**首轮验收门槛** 一周制作并试阅两版成片，10项事实逐条可回源，20名受众测试中≥70%能复述一项直接证据。

## 最小权限与异常处理

研究推论可能被误说成定论，照片版权不明。采用原始论文表述与授权或自行制作图示。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

先以内容系列验证观众留存，按条报价教育部门授权，测试正式采购。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
