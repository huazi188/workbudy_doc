## MVP 目标和用户

企业AI产品经理与质检负责人。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 业务题库、授权样本与模型对照决策页。

**对照流程** 比供应商演示，按同一输入比较准确率、延迟和单位成本。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选客服或文档分类一项，盲标双人复核并记录意见分歧。

**首轮验收门槛** ≥60个固定任务，全部可复算，优胜模型关键任务正确率≥90%。

## 最小权限与异常处理

版本漂移，冻结时间、版本和提示词。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按工作流收一次评测费，向两位实际采购人提交固定范围报价。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
