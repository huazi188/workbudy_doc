## MVP 目标和用户

有单工位缺陷漏检负担的机加工厂质量主管采购，工位检验员使用。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 交付可回放的视觉工位、缺陷分级样本册和人工复核台账，输入料号、流水线节拍和带真值样件。

**对照流程** 对比同工位人工目检，以同批件盲测标注匹配率、漏检率和误剔除，复核工位负荷单计。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选一种高频缺陷及稳定光照的工位，先放置相机旁路，两周用同班次人工对照报告迭代。

**首轮验收门槛** 拟以一类料号做分层盲测，至少300件有真值缺陷样本，目标缺陷漏检≤0.4%，另以合格件测误报≤2%。

## 最小权限与异常处理

低发生缺陷收集慢，留出历史缺陷作为盲测，量产上线前继续双检，设置车间现行验收方式为兜底。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按单工位收固定试点价并将验证与上线区分，试点首款支付后启动，增料号按样件成本报价。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
