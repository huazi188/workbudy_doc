## MVP 目标和用户

已在京东开店但缺直播运营的店主采购，商品运营与值班客服验收。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 用授权商品图、价格政策和品牌素材交付数字人脚本、定档、值班记录和场次订单来源表。

**对照流程** 与同店同期未开播时间段或已有人播的可比时段对照，按播放时长归一化。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 挑3家同品类未开播小店，锁定SKU和优惠条件，区分自然访客与直播来源订单。

**首轮验收门槛** 3店各完成≥4场，已排场次准时率≥90%，介绍价格和售后政策无严重错误，至少1店签续费。

## 最小权限与异常处理

误报优惠和未授权主播形象。开播前批准脚本，活动期复核价格，配备真人停播权限。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按店收两周试播费，按有效直播小时包月，记录商家愿意为多少可用时段续费。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
