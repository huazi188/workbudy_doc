## MVP 目标和用户

接受海外个性化询单的绢花厂外贸经理采购，打样师和报价员使用。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 把询单图片、尺寸、材质和工艺限制变成可编辑样稿与待确认报价，保留原始要求。

**对照流程** 与传统邮件交接、人工设计和报价表对照首轮交付时间及打样师改动量。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 两家同品类厂各回放10条授权询单，由打样师盲评，报价使用工厂确认的成本表。

**首轮验收门槛** 20条有完整工艺资料的询单中≥15条生成可审样稿，首稿中位时长下降≥50%，报价逐条复核。

## 最小权限与异常处理

效果图与可制造结构不符或混入客户图案。仅使用授权图，建立工艺约束和打样师签字。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按厂/月与按确认样稿两种计费试报，请试用厂为第二批客户样稿付费。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
