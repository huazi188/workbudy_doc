# 🎯 雷鸟AI眼镜应用生态 - 需求规格 (Spec)

**版本**: v1.0  
**日期**: 2026-11-16  
**产品名称**: RayGlass Notes (暂定)  
**目标用户**: 商务人士、记者、律师、PM  
**核心场景**: 会议速记、出行记录

---

## 1. 产品定义

### 产品概述

为雷鸟AI眼镜用户提供的智能会议速记与出行记录工具，通过眼镜端实时语音转写、智能摘要、云端同步，帮助用户快速记录和管理信息，提升工作效率。

### 用户画像

**Primary User: 商务人士 (40%)**
- 年龄: 25-40岁
- 职位: PM、管理、销售、顾问
- 痛点: 会议记录繁琐、信息容易遗漏、会后整理费时
- 使用频次: 日均1-2场会议

**Secondary User: 出行爱好者 (30%)**
- 年龄: 20-35岁
- 职位: 记者、自媒体、旅游博主
- 痛点: 临时灵感容易遗忘、记录工具笨重
- 使用频次: 周3-4次

**Tertiary User: 视障/低视力人群 (15%)**
- 年龄: 任意
- 痛点: 出行无障碍、信息获取困难
- 使用频次: 每日1-2次

**Other: 普通用户 (15%)**
- 日常备忘、快速记录

### 核心价值主张

| 用户群 | 价值主张 | 定量益处 |
|-------|--------|---------|
| 商务人士 | 会议自动记录 + 智能摘要 | 节省50%会后整理时间 |
| 出行爱好者 | 一键记录 + 云同步 | 不用拿手机，眼镜直接记 |
| 视障人群 | 无障碍导航 + 读字 | 出行更安全、信息更便捷 |

## 2. 功能规格

### 核心功能 (P0 - Must Have)

#### 2.1 会议速记

**功能1.1: 一键开启转写**
- 用户在眼镜上按压侧边按钮，语音自动转写开始
- 实时显示转写进度 (屏显"正在记录...")
- 支持中文、英文、中英混合自动识别
- 转写精度要求: ≥85% (行业基准90%)

**功能1.2: 实时转写显示**
- 眼镜屏幕上实时显示最近3行转写内容
- 字体大小可调 (便于近视/远视用户)
- 支持暂停/继续转写

**功能1.3: 时间轴记录**
- 每条记录精确到秒 (HH:MM:SS)
- 关键词自动标记 (如数字、人名、决策词)
- 支持多轨道录音 (区分不同麦克风)

**功能1.4: 会议结束自动保存**
- 用户摘下眼镜或按结束按钮时自动保存
- 自动上传至云端 (断网时本地缓存)
- 生成会议ID便于查找

#### 2.2 智能摘要 (P1)

**功能2.1: 自动生成摘要**
- 会议结束后5分钟内生成摘要
- 摘要包含: 核心要点(3-5条) + 待办项 + 关键数字
- 用户可在手机App查看完整摘要

**功能2.2: 智能提取**
- 自动识别"决策"、"待办"、"风险"等关键信息
- 支持手动编辑和标记

#### 2.3 云端同步

**功能3.1: 自动上传**
- WiFi/4G下自动上传录音和转写
- 优先上传转写文本(轻量)，后上传音频(重量)
- 上传进度可见

**功能3.2: 跨端查看**
- 手机App端实时查看最新记录
- PC浏览器也可查看 (后期)

#### 2.4 数据导出

**功能4.1: 多格式导出**
- 支持导出为: 文本(.txt) / Word(.docx) / PDF / 音频(.m4a)
- 分享链接给他人 (设置有效期)

#### 2.5 稳定性保障

**功能5.1: 断网缓存**
- 无网时自动缓存录音 (本地存储空间允许)
- 网络恢复后自动同步
- 用户可手动触发同步

**功能5.2: 低电量保护**
- 电量≤20%时自动保存并提示
- 电量≤5%时强制上传 (如网络可用)

---

### 扩展功能 (P1/P2)

#### 2.6 场景识别

**功能6.1: 自动场景切换**
- 根据GPS/时间/声音识别当前场景
- 场景类型: 会议室、办公室、户外、汽车等
- 自动切换对应的转写模式 (会议模式/出行模式)

**功能6.2: 出行记录模式**
- 记录GPS轨迹 + 语音备忘
- 在地图上重放行程

#### 2.7 用户系统

**功能7.1: 账户管理**
- 雷鸟账号一键登录
- 支持修改密码、隐私设置

**功能7.2: 记录管理**
- 标签分类 (会议/出行/其他)
- 搜索功能 (关键词搜索)
- 删除/归档功能

## 3. 技术规格

### 3.1 平台要求

**硬件兼容性**
- 雷鸟 iO (主要目标)
- 雷鸟 GT Max (次要目标)
- 其他雷鸟机型 (后续适配)

**操作系统**
- 雷鸟OS (基于Android)
- 最低API Level: 29

**伴侣App**
- iOS 15+ 
- Android 10+

### 3.2 API 调用清单

| API | 服务商 | 调用量/月 | 成本/月 |
|-----|--------|---------|--------|
| 语音转写 | 阿里云/讯飞 | 10万分钟 | 2000元 |
| AI摘要 | 通义千问/文心 | 2万次 | 100元 |
| 云存储 | 阿里云OSS | 50GB | 72元 |
| 地理编码 | 高德地图 | 5万次 | 150元 |

### 3.3 数据存储

**用户数据**
- PostgreSQL: 用户账户、会话记录元数据
- MongoDB: 转写文本、摘要内容
- Redis: 缓存、会话状态

**文件存储**
- 阿里云OSS: 音频文件、导出文件

### 3.4 性能要求

| 指标 | 要求 |
|-----|------|
| 语音转写延迟 | <3秒 (实时显示前3行) |
| 云同步延迟 | <5分钟 (会议结束后) |
| App加载速度 | <2秒 |
| API响应时间 | <1秒 (95百分位) |
| 系统崩溃率 | <1% |
| API可用性 | >99.5% |
