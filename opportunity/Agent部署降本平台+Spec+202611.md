## MVP 目标和用户

签结果费的客服 Agent 厂交付主管采购，解决方案工程师使用模板，客户现场IT授予范围。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 把获授权的客服环境接入、话术版本、脱敏回归样本和分段验收固化到环境模板，交付可复跑的部署报告。

**对照流程** 以手工配环境和逐项找测试记录为基准，比较两次类型相近部署的人时和复核问题数。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 找一家获授权的客服方案商，回顾最近两单的工时，做沙盒环境全量重跑并按人时与漏验量验收。

**首轮验收门槛** 拟两个测试租户均能回放至少50条脱敏案例，配置与验收人时下降≥30%，越租户访问和错发为0。

## 最小权限与异常处理

配置污染和外发误触发，使用隔离租户、占位密钥与客户明确授权，关闭自动外发，按租户回滚。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按新部署客户数或交付团队席位收费，先签一个实付部署诊断加样板实施，并以第二租户复用考虑扩购。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 先验证需求，再决定试点**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
