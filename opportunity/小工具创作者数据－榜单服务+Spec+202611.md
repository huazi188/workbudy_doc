## MVP 目标和用户

小红书小工具创作者及创作者机构订阅，选题编辑核对公开表现。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 基于许可公开页面统计工具类型、样本频次和内容形式，交付带数据口径与时间范围的周榜。

**对照流程** 与人工在社区看热门帖子比较重复率、周更新用时和实际选题采纳。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 选2个工具类别，逐周固定参考页面或时间窗口，以创作者采纳和后续工具反馈回查。

**首轮验收门槛** 连续发3期，原始样本出处可审计≥95%，20位读者中至少5位用榜单确定实际工具选题。

## 最小权限与异常处理

流量受个性化与推荐偏差影响。仅用许可来源，披露样本条件并剔除重复。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

免费发布摘要，按周或每月卖细分榜单及选题说明，以首月付费5人作为验证。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
