## MVP 目标和用户

多Agent业务运维负责人和质检运营员。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 任务完成与实际产出差异对账、告警与人工复核记录。

**对照流程** 比运行工具绿灯和人工巡检，测已知静默漏项。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 对客户现有运行记录做授权只读对照，注入合成失败样本。

**首轮验收门槛** 30个封闭任务中人为设置≥5类可控遗漏，检出率≥90%。

## 最小权限与异常处理

监控读取敏感输入，使用元数据和脱敏摘要。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按监控工作流订阅，销售首周基线诊断。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 先验证需求，再决定试点**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
