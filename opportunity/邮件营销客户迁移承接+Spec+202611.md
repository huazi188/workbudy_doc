## MVP 目标和用户

DTC 独立站运营负责人采购，邮件营销专员与客户 IT 验收。 在获授权的样本上完整演示一次从接收输入到交付、复核和取证的流程。

**交付件和输入** 从授权联系人、同意状态、退订抑制名单及自动化流程生成迁移映射、演练报告和回滚清单。

**对照流程** 对照品牌自迁或原工具迁移支持，比较活动停摆和标签映射人工核对量。

## 功能和验收

| 功能 | 验收方式 |
|---|---|
| P0 · 录入样本和基线 | 记录样本来源、授权、日期与纳入理由，锁定对照范围。必填信息缺失则退回补齐。 |
| P0 · 生成或制作业务交付件 | 按下述试点样本覆盖正常项和例外项，验收人能复核每项结论所依据的输入。 |
| P0 · 复核和业务接收 | 记录复核人、修订项、操作时间与最终状态。触及场景边界时暂停，交还原流程负责人。 |
| P0 · 验收证据 | 交付原流程和试点结果的同口径对照，列出分子、分母、测量区间、缺测和失败项。 |
| P1 · 后续扩展 | 首次流程验收并出现真实购买信号后，评审接入频率、角色范围和数据覆盖。 |

**测量协议** 导出一组处于不同订阅状态的测试样本，对一个原有欢迎旅程做发送前复核。

**首轮验收门槛** 500条授权联系人试迁中退订映射保持100%，10个核心标签映射符合约定，试发只到内部名单。

## 最小权限与异常处理

遗漏退订或发现联系人授权不明时冻结导入，切换由客户验收后执行。 样本授权、输入版本与人工修改均应可追溯。由业务验收人确认输出用途，原流程负责人能够停止试点并接回未完成任务。

## 业务验收

按联系人阶梯与自动化数报一次性迁移，用已计划迁移团队的付费小样验价。 状态按样本可用、试点交付、业务验收、付费确认逐项记录。评审结论为 **GO · 验证需求与付费**。已落实数据授权、业务负责人和对照基线后，方可启动受控试点。
